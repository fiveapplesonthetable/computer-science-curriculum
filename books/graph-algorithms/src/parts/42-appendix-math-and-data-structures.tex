\section{Asymptotics: Big-O, Big-Theta, Big-Omega}
\label{ch42:asymptotics}

Exact instruction counts depend on compiler details and hardware speed. Algorithm analysis instead tracks how operation counts scale as the input size $n$ grows, discarding constant multipliers and lower-order terms to isolate the growth rate.

\begin{intuitionbox}
Think of two algorithms as two functions $f(n)$ and $g(n)$ counting basic operations on inputs of size $n$. Big-O states an asymptotic \emph{ceiling}: $f = \Oh(g)$ means $f$ grows no faster than a constant multiple of $g$ once $n$ is large enough. Big-Omega states an asymptotic \emph{floor}: $f = \Om(g)$ means $f$ grows at least as fast as a positive constant multiple of $g$. Big-Theta states both at once: $f = \Th(g)$ pins the growth rate from above and below, as shown in Figure~\ref{ch42:fig-asymptotics}. Saying merge sort (sorting by recursively halving and merging) runs in $\Th(n\log n)$ time means its cost stays sandwiched between $c_1 n\log n$ and $c_2 n\log n$ for all large $n$.
\end{intuitionbox}

\begin{definition}[Asymptotic classes]
\label{ch42:def-bigo}
Let $f, g : \N \to \R_{\ge 0}$ be functions from the natural numbers $\N = \{0,1,2,\dots\}$ (input sizes) to the nonnegative real numbers $\R_{\ge 0}$ (operation counts). Then
\begin{align*}
f = \Oh(g) &\iff \text{there exist constants } c > 0 \text{ and } n_0 \text{ such that } f(n) \le c\,g(n) \text{ for all } n \ge n_0, \\
f = \Om(g) &\iff \text{there exist constants } c > 0 \text{ and } n_0 \text{ such that } f(n) \ge c\,g(n) \text{ for all } n \ge n_0, \\
f = \Th(g) &\iff f = \Oh(g) \text{ and } f = \Om(g).
\end{align*}
When $g(n) > 0$ for large $n$ and $\lim_{n\to\infty} f(n)/g(n) = 0$, we write $f = o(g)$ (read ``little-oh of $g$''), meaning $f$ has a strictly smaller growth rate than $g$.
\end{definition}

The ``$=$'' sign in $f = \Oh(g)$ is traditional shorthand: $\Oh(g)$ is a \emph{set} of functions, and $f = \Oh(g)$ means $f \in \Oh(g)$. You can chain it from left to right ($n^2 + 3n = n^2 + \Oh(n) = \Oh(n^2)$), because every function in the left set belongs to the right set, but never reverse it ($\Oh(n^2) = n^2 + 3n$ is meaningless).

\begin{example}[Discarding lower-order terms]
\label{ch42:ex-discard}
Let $f(n) = 3n^2 + 50n + 1000$. Then $f = \Th(n^2)$. For the upper bound, once $n \ge 50$ we have $50n \le n^2$ and $1000 \le n^2$, so
\[
  f(n) \le 3n^2 + n^2 + n^2 = 5n^2,
\]
giving $f = \Oh(n^2)$ with $c = 5$ and $n_0 = 50$. For the lower bound, $50n + 1000 \ge 0$ for all $n \ge 0$, so $f(n) \ge 3n^2$, giving $f = \Om(n^2)$ with $c = 3$ and $n_0 = 0$. The linear and constant terms are absorbed into the multiplier $c$; only the leading $n^2$ term determines the class.
\end{example}

Four rules follow directly from Definition~\ref{ch42:def-bigo}:

\begin{itemize}
\item \textbf{Transitivity.} If $f = \Oh(g)$ and $g = \Oh(h)$, then $f = \Oh(h)$.
\item \textbf{Sum rule.} $\Oh(f) + \Oh(g) = \Oh(\max(f, g))$. Running two phases back to back costs the slower phase's growth rate.
\item \textbf{Product rule.} If $f_1 = \Oh(g_1)$ and $f_2 = \Oh(g_2)$, then $f_1 f_2 = \Oh(g_1 g_2)$. A loop of $\Oh(g_1)$ iterations doing $\Oh(g_2)$ work each runs in $\Oh(g_1 g_2)$ time.
\item \textbf{Logarithm bases.} For any constants $a, b > 1$, the change-of-base formula $\log_a n = \log_b n / \log_b a$ implies $\log_a n = \Th(\log_b n)$, so we write $\Oh(\log n)$ without specifying a base. In an exponent, however, the base changes the growth class: $2^n = o(3^n)$ because $(2/3)^n \to 0$.
\end{itemize}

\begin{trapbox}
When a loop runs $i$ from $1$ to $n$ with variable inner cost, multiplying the iteration count by the worst-case iteration can overcount by a full factor. If iteration $i$ costs $\Oh(i)$, summing gives
\[
  \sum_{i=1}^n \Oh(i) = \Oh\!\left(\frac{n(n+1)}{2}\right) = \Oh(n^2),
\]
which matches $n \cdot \Oh(n)$ because the average term is $n/2$. By contrast, when the work shrinks by a constant factor at each level (a \emph{geometric} decrease, such as $n/2^i$ across the levels of a binary tree), summing gives
\[
  \sum_{i=0}^{\floor{\log_2 n}} \frac{n}{2^i} < 2n = \Oh(n),
\]
whereas multiplying $\Oh(\log n)$ levels by the largest level $\Oh(n)$ gives the loose bound $\Oh(n\log n)$. Sum the per-step costs before simplifying.
\end{trapbox}

\begin{connectionbox}
Informal speech often says ``this algorithm is $\Oh(n^2)$'' to mean ``its running time grows quadratically.'' Following Donald Knuth's convention, this book keeps the three symbols distinct: $\Oh$ states an upper bound (the algorithm is \emph{at most} this slow), $\Om$ states a lower bound (the problem or algorithm requires \emph{at least} this much work), and $\Th$ states that the upper and lower bounds match.
\end{connectionbox}

\subsection{A hierarchy to memorize}

Writing $f \prec g$ to mean $f = o(g)$, these standard functions grow in strictly increasing order for any constant $0 < \eps < 1$:
\[
1 \;\prec\; \log\log n \;\prec\; \log n \;\prec\; n^{\eps} \;\prec\; n \;\prec\; n\log n \;\prec\; n^2
\;\prec\; n^3 \;\prec\; 2^n \;\prec\; n! \;\prec\; n^n.
\]
Every positive power $n^{\eps}$ eventually overtakes any \emph{polylogarithmic} function $(\log n)^k$ (a fixed power $k > 0$ of $\log n$), and every exponential $c^n$ ($c > 1$) overtakes any polynomial $n^k$. Complexity theory draws its main dividing line between polynomial time, denoted $\poly(n) = n^{\Oh(1)}$ (bounded by $n^c$ for some constant $c$, treated as computationally \emph{tractable}), and exponential time $2^{\Om(n)}$ (growing at least as fast as $2^{cn}$ for some $c > 0$, \emph{intractable} at large scale).

\section{Amortized Analysis}
\label{ch42:amortized}

Some data structures perform most operations quickly while occasionally paying for a large reorganization. A \emph{dynamic array} stores items in a contiguous block of capacity $\text{cap}$ and doubles that block whenever it fills: appending an item while $\text{size} < \text{cap}$ takes $\Oh(1)$ time, whereas appending to a full array allocates a block of size $2\cdot\text{cap}$ and copies all existing items in $\Oh(n)$ time. Multiplying $n$ operations by the $\Oh(n)$ worst-case single step suggests $\Oh(n^2)$ total time, yet any sequence of $n$ appends from empty takes $\Oh(n)$ time in total, or $\Oh(1)$ \emph{amortized} time per operation. Unlike average-case analysis, amortized analysis makes no probability assumptions about the input; it bounds the guaranteed average cost per step over \emph{every} sequence of operations.

\begin{intuitionbox}
Think of a prepaid transit card. Each cheap operation pays slightly more than its immediate cost, storing the surplus as credit on the card. When an expensive reorganization occurs, stored credit pays for the extra work. As long as the card balance never drops below zero, the total amount charged across the whole sequence is at least the total actual work performed.
\end{intuitionbox}

Three standard bookkeeping styles prove amortized bounds; all three establish the same total-cost guarantee.

\paragraph{Aggregate method.} Prove an upper bound $T(n)$ on the total actual cost of any sequence of $n$ operations, then assign every operation the amortized cost $T(n)/n$. Starting from capacity $1$, $n$ appends to a doubling array trigger copies at sizes $1, 2, 4, \dots, 2^{\floor{\log_2(n-1)}}$ (for $n \ge 2$, where the \emph{floor} $\floor{x}$ rounds $x$ down to the nearest integer). The copy counts sum to at most $2n - 1$, plus $n$ direct writes, giving $T(n) < 3n = \Oh(n)$ total and $\Oh(1)$ amortized per append.

\paragraph{Accounting method.} Assign operation $i$ an \emph{amortized charge} $\amort_i$ alongside its true cost $c_i$, subject to the invariant that cumulative charges never fall behind cumulative true costs on any prefix:
\[
  \sum_{i=1}^k \amort_i \ge \sum_{i=1}^k c_i \qquad \text{for every } k = 1, \dots, n.
\]
The excess $\sum_{i=1}^k (\amort_i - c_i) \ge 0$ is the stored credit. For the doubling array, charge $\amort_i = 3$ credits per append: spend $1$ credit to write the new item, and store $2$ credits to pay for copying both the new item and one older unbanked item during the next resize. Because the credit balance never goes negative, the total true cost is at most $3n$.

\paragraph{Potential method.} Represent stored credit as a \emph{potential function} $\Phi$ that maps each data-structure state $D$ to a real number $\Phi(D) \ge 0$, starting at $\Phi(D_0) = 0$ for the initial state $D_0$. Letting $D_i$ denote the state after operation $i$, define the $i$-th amortized cost as
\[
  \amort_i = c_i + \Phi(D_i) - \Phi(D_{i-1}).
\]
Summing across $n$ operations produces a \emph{telescoping sum}, in which every intermediate $+\Phi(D_i)$ cancels with the next step's $-\Phi(D_i)$:
\begin{align*}
  \sum_{i=1}^n \amort_i
  &= \sum_{i=1}^n \bigl(c_i + \Phi(D_i) - \Phi(D_{i-1})\bigr) \\
  &= \sum_{i=1}^n c_i + \Phi(D_n) - \Phi(D_0) && \text{(intermediate terms cancel)} \\
  &\ge \sum_{i=1}^n c_i && \text{(since $\Phi(D_n) \ge 0$ and $\Phi(D_0) = 0$).}
\end{align*}
Thus $\sum_{i=1}^n \amort_i$ upper-bounds the true total cost. Designing a proof reduces to choosing $\Phi$ so that $\Phi(D_i) - \Phi(D_{i-1})$ is strongly negative whenever $c_i$ is large.

\begin{recoverybox}
\textbf{Pause and think}: Why does charging $3$ credits per append keep the bank balance nonnegative? Immediately after the array doubles from capacity $k$ to $2k$, it holds $k$ items with $0$ credits stored on them. Each of the next $k$ appends spends $1$ credit on its write and banks $2$ credits. When the array reaches $2k$ items and fills, $2k$ credits sit in the bank, matching the $2k$ item copies required by the next doubling.
\end{recoverybox}

Figure~\ref{ch42:fig-amortized-bank} traces this cycle with potential $\Phi(D_i) = 2 s_i - \text{cap}_i$, where $s_i$ is the number of stored items and $\text{cap}_i$ is the array capacity after step $i$ (taking $\Phi(D_0) = 0$ on the empty structure). Non-resizing appends raise $s_i$ by $1$ and $\Phi$ by $+2$; a resize from $4$ to $8$ on the fifth append spends the $4$ stored credits on the $4$ copies and banks $2$ fresh credits on $x_5$, dropping $\Phi$ from $4$ to $2$ so that $\amort_5 = 5 + (2 - 4) = 3$.

\begin{example}[Binary counter]
\label{ch42:ex-counter}
Increment a $k$-bit binary counter $n$ times starting from $0$. A single increment can flip up to $k$ bits (for instance, $0111_2 \to 1000_2$ flips four), so the worst-case single step is $\Oh(k)$. Define $\Phi(D_i)$ to be the number of $1$ bits in the counter after step $i$, with $\Phi(D_0) = 0$. If step $i$ flips $t$ trailing $1$s to $0$ and sets the next $0$ bit to $1$, its true bit-flip cost is $c_i = t + 1$ and the number of $1$ bits changes by $\Delta\Phi = -t + 1$, giving
\[
  \amort_i = (t + 1) + (-t + 1) = 2 = \Oh(1).
\]
The drop in $\Phi$ cancels the $t$ cascading resets, proving that $n$ increments flip at most $2n = \Oh(n)$ bits in total rather than $\Oh(nk)$.
\end{example}

\begin{whybox}
Why can any nonnegative potential be trusted? Because the telescoping sum is an algebraic identity. The bound $\sum_{i=1}^n c_i \le \sum_{i=1}^n \amort_i$ uses only $\Phi(D_n) \ge \Phi(D_0) = 0$. Every valid potential produces a sound upper bound on total runtime; choosing a sharper $\Phi$ produces a tighter bound. The same potential argument establishes the $\Oh(\log n)$ amortized cost of splay trees (self-adjusting binary search trees, Chapter~22) and the near-constant amortized cost of union-find below.
\end{whybox}

\section{Union-Find (Disjoint-Set Union)}
\label{ch42:unionfind}

Union-find maintains a partition of $\{1,\dots,n\}$ into non-overlapping subsets under two operations: $\find(x)$ returns a fixed \emph{canonical representative} (one chosen member that labels $x$'s entire subset), and $\union(x,y)$ merges the subsets containing $x$ and $y$. Testing $\find(x) = \find(y)$ answers whether $x$ and $y$ lie in the same subset. Kruskal's minimum-spanning-tree (MST) algorithm uses this test to check whether adding an edge would close a cycle; the same structure supports offline connectivity queries (where the full sequence of edge insertions and queries is known beforehand) and grid percolation simulations (which test when randomly opened cells form a connected path across a grid).

\begin{intuitionbox}
Store each subset as a rooted tree of parent pointers whose root serves as the canonical representative. $\find(x)$ follows parent pointers up to the root; $\union(x,y)$ attaches one root under the other. Two rules keep these trees shallow. \emph{Union by rank} maintains an integer $\textit{rank}$ at each root and attaches the lower-rank root under the higher-rank root, so height grows only when two equal-rank trees merge. \emph{Path compression}, shown in Figure~\ref{ch42:fig-dsu-compression}, rewrites the parent pointer of every node visited during $\find(x)$ to point straight at the root, shortening future searches along that branch.
\end{intuitionbox}

\begin{algorithm}[H]
\caption{Union-Find with union by rank and path compression}
\DontPrintSemicolon
\SetKwFunction{FMake}{MakeSet}\SetKwFunction{FFind}{Find}\SetKwFunction{FUnion}{Union}
\SetKwProg{Fn}{function}{:}{}
\Fn{\FMake{$x$}}{$\textit{parent}[x]\gets x$;\quad $\textit{rank}[x]\gets 0$\;}
\Fn{\FFind{$x$}}{
  \If{$\textit{parent}[x]\ne x$}{$\textit{parent}[x]\gets \FFind{\textit{parent}[x]}$\tcp*{path compression}}
  \Return $\textit{parent}[x]$\;
}
\Fn{\FUnion{$x,y$}}{
  $rx\gets \FFind{x}$;\quad $ry\gets \FFind{y}$\;
  \lIf{$rx=ry$}{\Return}
  \If{$\textit{rank}[rx]<\textit{rank}[ry]$}{swap $rx\leftrightarrow ry$\tcp*{attach smaller under larger}}
  $\textit{parent}[ry]\gets rx$\;
  \lIf{$\textit{rank}[rx]=\textit{rank}[ry]$}{$\textit{rank}[rx]\gets\textit{rank}[rx]+1$}
}
\end{algorithm}

\begin{labbox}
Start with six singleton sets $\{1\},\dots,\{6\}$, all at rank $0$, and process the edge sequence $\{(1,2),(3,4),(2,4),(5,6),(2,6)\}$ as Kruskal's algorithm would:
\begin{itemize}
\item $\union(1,2)$: ranks tie at $0$; $2$ attaches under $1$, and $\textit{rank}[1]$ becomes $1$. Subset: $\{1,2\}$.
\item $\union(3,4)$: $4$ attaches under $3$, and $\textit{rank}[3]$ becomes $1$. Active subsets: $\{1,2\}, \{3,4\}$.
\item $\union(2,4)$: $\find(2)=1$ and $\find(4)=3$ tie at rank $1$; $3$ attaches under $1$, and $\textit{rank}[1]$ becomes $2$. Subset: $\{1,2,3,4\}$.
\item $\union(5,6)$: $6$ attaches under $5$, and $\textit{rank}[5]$ becomes $1$. Subsets: $\{1,2,3,4\}, \{5,6\}$.
\item $\union(2,6)$: $\find(2)=1$ (rank $2$) beats $\find(6)=5$ (rank $1$), so $5$ attaches under $1$ without changing $\textit{rank}[1]=2$. One subset remains: $\{1,2,3,4,5,6\}$.
\end{itemize}
Because path compression can shorten subtrees without lowering $\textit{rank}$, $\textit{rank}$ tracks an \emph{upper bound} on tree height rather than exact height; a subsequent $\find(6)$ redirects $6 \to 5 \to 1$ to $6 \to 1$.
\end{labbox}

\subsection{Why it is fast}

\begin{theorem}[Tarjan, 1975]
\label{ch42:thm-uf}
Starting from $n$ singleton sets, any sequence of $m \ge n$ \find\ and \union\ operations using union by rank and path compression runs in $\Oh(m\,\alpha(n))$ time, where $\alpha(n)$ is the inverse Ackermann function.
\end{theorem}

Ackermann's function stacks recursive operations (addition, multiplication, exponentiation, iterated power towers, and higher layers) so that its values outgrow every fixed tower of powers; its functional inverse $\alpha(n)$ counts how many layers are needed to reach $n$, which stays at most $4$ for every $n \le 2^{2^{2^{65536}}}$. In practice, union-find takes constant amortized time per operation. Tarjan's sharp bound uses a multi-level potential function; Lemma~\ref{ch42:lem-rank} proves the foundational $\Oh(\log n)$ bound from union by rank alone, illustrated in Figure~\ref{ch42:fig-union-rank}.

\begin{recoverybox}
\textbf{Pause and think}: If path compression flattens every traversed path straight to the root, why isn't the amortized cost strictly $\Oh(1)$? Because $\union$ links two roots in $\Oh(1)$ time without compressing their subtrees; carefully interleaved unions and partial finds can build fresh multi-step paths in unvisited branches faster than a constant charge per operation can pay down.
\end{recoverybox}

\begin{lemma}[Rank bounds]
\label{ch42:lem-rank}
Under union by rank (with or without path compression), a root of rank $r$ has at least $2^r$ nodes in its tree, every tree has height at most $\floor{\log_2 n}$, and node ranks strictly increase from child to parent along every path to a root.
\end{lemma}

\begin{proof}
Induct on the number of unions. Initially every node is a rank-$0$ root of size $1 = 2^0$. A root's rank increases to $r$ only when $\union$ links two roots of equal rank $r-1$; by the inductive hypothesis each has at least $2^{r-1}$ nodes, so the combined tree has at least $2^{r-1} + 2^{r-1} = 2^r$ nodes. When two roots of unequal rank merge, the higher-rank root keeps its rank and gains nodes, preserving the bound. Since at most $n$ nodes exist, $2^r \le n$, giving $r \le \floor{\log_2 n}$. Path compression moves nodes closer to the same root without altering any node's rank or root subtree size. Finally, whenever node $y$ is attached under $x$ (or re-pointed to an ancestor during compression), $x$'s rank becomes strictly greater than $y$'s, so height cannot exceed the root's rank.
\end{proof}

Without path compression, Lemma~\ref{ch42:lem-rank} already bounds each operation by $\Oh(\log n)$. Adding path compression reduces the amortized cost to $\Oh(\log^* n)$ by an elementary bucket-grouping argument -- where the \emph{iterated logarithm} $\log^* n$ counts how many times $\log_2$ must be applied before the value drops to $1$ or below (for example, $\log^* 65536 = 4$ via $65536 \to 16 \to 4 \to 2 \to 1$) -- and down to $\Oh(\alpha(n))$ in Theorem~\ref{ch42:thm-uf}.

\begin{complexitybox}
\textbf{Union-find.} Space $\Oh(n)$. With both union by rank and path compression: $m$ operations in $\Oh(m\,\alpha(n))$ time. With either heuristic alone: $\Oh(\log n)$ per operation (worst-case for union by rank alone, amortized for path compression alone). With neither heuristic: $\Oh(n)$ per operation in the worst case.
\end{complexitybox}

\begin{applicationbox}
Kruskal's MST algorithm sorts $m$ edges in $\Oh(m\log m)$ time and runs $\Oh(m)$ union-find calls in $\Oh(m\,\alpha(n))$ time, so sorting dominates the runtime. Union-find also powers Tarjan's offline lowest common ancestor (LCA) algorithm, incremental connected components, undirected cycle detection, and component contraction in Bor\r{u}vka's MST algorithm. Whenever a graph algorithm merges vertex sets without splitting them, union-find is the standard representation.
\end{applicationbox}

\section{Heaps and Priority Queues}
\label{ch42:heaps}

A \emph{priority queue} stores items that each carry a numerical priority called a \emph{key}, supporting \textsc{Insert}, \textsc{ExtractMin} (remove and return an item of minimum key), and \textsc{DecreaseKey} (lower an existing item's key). Dijkstra's shortest-path algorithm and Prim's MST algorithm repeatedly extract the closest frontier vertex and relax its outgoing edges -- checking whether each edge lowers a neighbor's best-known distance or connection weight -- so the priority queue's operation costs determine both algorithms' running times.

\begin{intuitionbox}
A \emph{binary min-heap} is a \emph{complete binary tree} (every level is completely filled except possibly the bottom level, which fills consecutively from left to right) satisfying the \emph{heap-order property}: every node's key is less than or equal to its children's keys. Because a complete tree has no gaps, storing nodes level by level in a $1$-indexed array $A[1\dots s]$ needs no pointers, as illustrated in Figure~\ref{ch42:fig-binary-heap}: the minimum sits at the root $A[1]$, index $i$ has children at $2i$ and $2i+1$, and any node $i \ge 2$ has parent $\floor{i/2}$. \textsc{Insert} appends the new key at $A[s+1]$ and \emph{sifts up}, swapping with its parent while smaller; \textsc{ExtractMin} moves $A[s]$ to $A[1]$ and \emph{sifts down}, swapping with its smaller child while larger. Both walk a single root-to-leaf path in $\Oh(\log n)$ time.
\end{intuitionbox}

\begin{algorithm}[H]
\caption{Binary-heap sift operations (min-heap, array $A$, size $s$)}
\DontPrintSemicolon
\SetKwFunction{FUp}{SiftUp}\SetKwFunction{FDown}{SiftDown}\SetKwFunction{FIns}{Insert}\SetKwFunction{FEx}{ExtractMin}
\SetKwProg{Fn}{function}{:}{}
\Fn{\FUp{$i$}}{
  \While{$i>1$ \textbf{and} $A[\lfloor i/2\rfloor] > A[i]$}{
    swap $A[i]\leftrightarrow A[\lfloor i/2\rfloor]$;\quad $i\gets\lfloor i/2\rfloor$\;}
}
\Fn{\FDown{$i$}}{
  \While{$2i\le s$}{
    $j\gets 2i$;\quad \lIf{$j+1\le s$ \textbf{and} $A[j+1]<A[j]$}{$j\gets j+1$}
    \lIf{$A[i]\le A[j]$}{\textbf{break}}
    swap $A[i]\leftrightarrow A[j]$;\quad $i\gets j$\;}
}
\Fn{\FIns{$x$}}{$s\gets s+1$;\ $A[s]\gets x$;\ \FUp{$s$}\;}
\Fn{\FEx{}}{$m\gets A[1]$;\ $A[1]\gets A[s]$;\ $s\gets s-1$;\ \FDown{$1$};\ \Return $m$\;}
\end{algorithm}

\begin{whybox}
Correctness rests on the heap-order invariant: \emph{after every operation, $A[\floor{i/2}] \le A[i]$ for all $2 \le i \le s$}. \textsc{SiftUp} restores this invariant when a newly appended leaf at index $s$ is smaller than its parent, moving the single violation upward until it stops; \textsc{SiftDown} restores it when a replacement key at the root is larger than a child, swapping with the \emph{smaller} child so the promoted child stays less than or equal to its sibling. Because a complete tree on $n$ nodes has height $\floor{\log_2 n}$, each sift performs $\Oh(\log n)$ comparisons, and transitivity along root-to-node paths keeps the global minimum at $A[1]$.
\end{whybox}

\begin{labbox}
Insert $5, 3, 8, 1, 4$ into an empty min-heap, then extract the minimum:
\begin{itemize}
\item Insert $5$: $[5]$.
\item Insert $3$: $[5,3] \to$ sift up ($3 < 5$) $\to [3,5]$.
\item Insert $8$: $[3,5,8]$ ($8 > 3$, stop).
\item Insert $1$: $[3,5,8,1] \to$ swap with parent $5$ at index $2$ $\to [3,1,8,5] \to$ swap with root $3$ $\to [1,3,8,5]$.
\item Insert $4$: $[1,3,8,5,4]$; parent of index $5$ is index $2$ (key $3 \le 4$), stop.
\end{itemize}
Now \textsc{ExtractMin} returns $1$, moves $4$ to $A[1]$ giving $[4,3,8,5]$, and sifts down: smaller child of $4$ is $3$ (index $2$), swap to $[3,4,8,5]$; only child of index $2$ is $5$ (index $4$), and $4 \le 5$, stop. Final array: $[3,4,8,5]$, with minimum $3$ at $A[1]$.
\end{labbox}

\paragraph{Heapify in linear time.} Inserting $n$ unsorted keys one by one takes $\Oh(n\log n)$ time, whereas running \textsc{SiftDown} bottom-up from index $\floor{n/2}$ down to $1$ builds a valid heap in $\Oh(n)$ time. Measure a node's \emph{height} $h$ upward from the leaves (leaves have $h=0$, the root has $H = \floor{\log_2 n}$). As Figure~\ref{ch42:fig-heap-sift} shows, an $n$-node complete binary tree has at most $\ceil{n/2^{h+1}}$ nodes at height $h$ (where the \emph{ceiling} $\ceil{x}$ rounds $x$ up to the nearest integer). Since $2^h \le n$ for every $0 \le h \le H$, we have $\ceil{n/2^{h+1}} \le n/2^h$, and \textsc{SiftDown} from height $h$ performs at most $h$ swaps. Summing across all heights gives
\begin{align*}
  \sum_{h=0}^{H} \ceil*{\frac{n}{2^{h+1}}}\, \Oh(h)
  &\le \sum_{h=0}^{H} \frac{n}{2^h}\, \Oh(h) \\
  &= \Oh\!\left(n \sum_{h=0}^{\infty} \frac{h}{2^h}\right)
  = \Oh(2n) = \Oh(n),
\end{align*}
using the series identity $\sum_{h=0}^{\infty} h/2^h = 2$. Half the nodes are leaves that do zero work, and only the single root can sift down $\floor{\log_2 n}$ levels.

\begin{complexitybox}
\textbf{Heaps.} Binary heap (tracking each item's array slot for \textsc{DecreaseKey}): \textsc{Insert}, \textsc{ExtractMin}, and \textsc{DecreaseKey} in $\Oh(\log n)$ time; bottom-up build in $\Oh(n)$ time; space $\Oh(n)$. \begin{connectionbox}
On a graph with $n$ vertices and $m$ edges, Dijkstra's algorithm (Chapter~7) and Prim's algorithm (Chapter~6) perform $n$ \textsc{ExtractMin} calls and at most $m$ \textsc{DecreaseKey} calls. Plugging in a binary heap gives $\Oh((n + m)\log n)$ time; plugging in a Fibonacci heap balances the two phases at $\Oh(m + n\log n)$, since the $m$ edge relaxations pay $\Oh(1)$ amortized per \textsc{DecreaseKey}.
\end{connectionbox}

\section{Fenwick Trees (Binary Indexed Trees)}
\label{ch42:fenwick}

Given an array $a[1\dots n]$, we want two operations: \emph{point update} (add $v$ to $a[i]$, written $a[i] \mathrel{+}= v$) and \emph{prefix sum} $\sum_{j=1}^i a[j]$. A plain array updates in $\Oh(1)$ time and sums prefixes in $\Oh(n)$ time; storing precomputed prefix sums reverses those two costs. A \emph{Fenwick tree} (or \emph{binary indexed tree}) performs both in $\Oh(\log n)$ time inside a single array $T[1\dots n]$ by indexing ranges through the \emph{lowest set bit} of $i$ -- the power of two corresponding to the rightmost $1$ in the binary representation of $i$ (for example, $6 = 0110_2$ has $\lowbit(6) = 0010_2 = 2$).

\begin{intuitionbox}
In two's-complement binary arithmetic (the standard signed integer representation, where $-i$ is obtained by flipping every bit of $i$ and adding $1$), the bitwise AND expression $\lowbit(i) = i \,\&\, (-i)$ isolates the rightmost $1$ bit of $i$: for $i = 6 = 0110_2$, flipping bits gives $1001_2$, adding $1$ gives $-6 = 1010_2$, and $0110_2 \,\&\, 1010_2 = 0010_2 = 2$. Store at $T[i]$ the sum of the $\lowbit(i)$ entries ending at $i$:
\[
  T[i] = \sum_{j = i - \lowbit(i) + 1}^{i} a[j].
\]
Figure~\ref{ch42:fig-fenwick-ranges} shows these blocks for $n=8$. Repeatedly subtracting $\lowbit(i)$ clears $1$ bits from right to left, stepping backward across non-overlapping power-of-two blocks that partition $[1, i]$ in at most $\floor{\log_2 n} + 1$ jumps.
\end{intuitionbox}

\begin{algorithm}[H]
\caption{Fenwick tree (array $T[1\dots n]$ initialized to $0$)}
\DontPrintSemicolon
\SetKwFunction{FUpd}{Update}\SetKwFunction{FQ}{PrefixSum}
\SetKwProg{Fn}{function}{:}{}
\Fn{\FUpd{$i,v$}}{
  \While{$i\le n$}{$T[i]\gets T[i]+v$;\quad $i\gets i+\lowbit(i)$\tcp*{climb to covering blocks}}
}
\Fn{\FQ{$i$}}{
  $s\gets 0$\;
  \While{$i>0$}{$s\gets s+T[i]$;\quad $i\gets i-\lowbit(i)$\tcp*{descend over tiling blocks}}
  \Return $s$\;
}
\end{algorithm}

Any range sum $\sum_{j=l}^r a[j]$ reduces to two prefix queries:
\[
  \sum_{j=l}^r a[j] = \FQ{$r$} - \FQ{$l-1$} \qquad (\text{taking } \FQ{$0$} = 0).
\]
Maintaining a \emph{difference array} $d[i] = a[i] - a[i-1]$ (where adding $v$ across $a[l\dots r]$ requires only two point updates, $d[l] \mathrel{+}= v$ and $d[r+1] \mathrel{-}= v$, while $\sum_{j=1}^i d[j]$ recovers $a[i]$) gives $\Oh(\log n)$ range updates and point queries; combining two Fenwick trees extends this to range updates and range sums (Exercise~\ref{ch42:ex-fenwick-range}).

\begin{whybox}
Why do the descending steps tile $[1,i]$ without gaps or overlaps? Cell $T[i]$ covers the integer interval $(i - \lowbit(i),\, i]$. Setting $i' = i - \lowbit(i)$ clears the lowest $1$ bit of $i$, so $T[i']$ covers $(i' - \lowbit(i'),\, i']$, ending at the exact boundary where $T[i]$ began. Clearing $1$ bits one at a time reaches $0$ after at most $\floor{\log_2 n} + 1$ steps, partitioning $[1,i]$. Conversely, adding $\lowbit(i)$ in \textsc{Update} steps through every index $k \ge i$ whose interval $(k - \lowbit(k),\, k]$ contains the modified position $i$.
\end{whybox}

\begin{labbox}
Start with $n=8$ and $T[1\dots 8] = 0$. Call \FUpd{$3, 5$}: $i$ visits $3$ ($\lowbit=1$) $\to 4$ ($\lowbit=4$) $\to 8$ ($\lowbit=8$) $\to 16 > 8$ (stop), adding $5$ to $T[3]$, $T[4]$, and $T[8]$. Next call \FQ{$6$}: $i$ visits $6$ ($+T[6]=0$) $\to 4$ ($+T[4]=5$) $\to 0$ (stop), returning $5$, which matches $a[3]=5$ inside $[1,6]$. Calling \FQ{$2$} visits $2 \to 0$ and returns $0$, so $\sum_{j=3}^6 a[j] = \FQ{6} - \FQ{2} = 5 - 0 = 5$ in three array reads rather than scanning four entries.
\end{labbox}

\section{Segment Trees}
\label{ch42:segtree}

A Fenwick tree relies on subtracting $\FQ{l-1}$ from $\FQ{r}$, which works for \emph{invertible} operations like addition (where $x + y$ can be undone by $-x$) and fails for operations like $\min$, where knowing $\min a[1\dots 7] = 1$ and $\min a[1\dots 1] = 1$ cannot recover $\min a[2\dots 7]$. A \emph{segment tree} answers range queries over $a[l\dots r]$ for \emph{any associative} operation $\oplus$ -- meaning $(x \oplus y) \oplus z = x \oplus (y \oplus z)$, including $\min$, $\max$, greatest common divisor ($\gcd$), sum, and matrix multiplication -- while supporting point updates and (via deferred updates below) range updates in $\Oh(\log n)$ time.

\begin{intuitionbox}
Build a balanced binary tree of height $\ceil{\log_2 n}$ by recursively halving the index interval $[1,n]$. The root owns $[1,n]$; an internal node owning $[l,r]$ splits at midpoint $m = \floor{(l+r)/2}$ into left child $[l,m]$ and right child $[m+1,r]$; leaves own single indices $[i,i]$. Every node stores the aggregate of its interval. As Figure~\ref{ch42:fig-segtree-query} shows, a query on $[ql, qr]$ returns a node's stored value intact whenever $[l,r] \subseteq [ql,qr]$ and recurses only when $[ql,qr]$ partially overlaps $[l,r]$, stitching the query answer from $\Oh(\log n)$ precomputed blocks.
\end{intuitionbox}

Like a binary heap, the tree is stored in a $1$-indexed array $t$ where root $p=1$ owns $[1,n]$ and node $p$'s children sit at $2p$ and $2p+1$ (allocating $4n$ slots accommodates arbitrary $n$, even when $n$ is not a power of two). When a branch's interval $[l,r]$ is disjoint from $[ql,qr]$, \textsc{Query} returns the operation's \emph{identity element} -- the neutral value $e$ satisfying $x \oplus e = e \oplus x = x$, which is $0$ for addition.

\begin{algorithm}[H]
\caption{Segment tree: build, range query, and point update (sum; node $p$ owns $[l,r]$)}
\DontPrintSemicolon
\SetKwFunction{FBuild}{Build}\SetKwFunction{FQ}{Query}\SetKwFunction{FUpd}{Update}
\SetKwProg{Fn}{function}{:}{}
\Fn{\FBuild{$p,l,r$}}{
  \lIf{$l=r$}{$t[p]\gets a[l]$; \Return}
  $m\gets\lfloor(l+r)/2\rfloor$\;
  \FBuild{$2p,l,m$};\quad \FBuild{$2p{+}1,m{+}1,r$}\;
  $t[p]\gets t[2p]+t[2p{+}1]$\;
}
\Fn{\FQ{$p,l,r,ql,qr$}}{
  \lIf{$qr<l$ \textbf{or} $r<ql$}{\Return $0$ \tcp*[f]{disjoint: identity}}
  \lIf{$ql\le l$ \textbf{and} $r\le qr$}{\Return $t[p]$ \tcp*[f]{fully inside}}
  $m\gets\lfloor(l+r)/2\rfloor$\;
  \Return \FQ{$2p,l,m,ql,qr$} $+$ \FQ{$2p{+}1,m{+}1,r,ql,qr$}\;
}
\Fn{\FUpd{$p,l,r,i,v$}}{
  \lIf{$l=r$}{$t[p]\gets v$; \Return}
  $m\gets\lfloor(l+r)/2\rfloor$\;
  \lIf{$i\le m$}{\FUpd{$2p,l,m,i,v$}}\lElse{\FUpd{$2p{+}1,m{+}1,r,i,v$}}
  $t[p]\gets t[2p]+t[2p{+}1]$\;
}
\end{algorithm}

\begin{theorem}[Query cost]
\label{ch42:thm-segtree}
A segment tree range query on $[1,n]$ visits $\Oh(\log n)$ nodes.
\end{theorem}

\begin{proof}
At any depth of the tree, the intervals $[l,r]$ of nodes at that depth are disjoint and ordered from left to right. A node recurses to its children only when its interval \emph{partially} overlaps $[ql,qr]$ (nodes completely inside or completely outside return immediately). At most two nodes at a given depth can partially overlap $[ql,qr]$: at most one straddling the left endpoint $ql$, and at most one straddling the right endpoint $qr$, since every node strictly between them lies completely inside $[ql,qr]$ and every node outside them is disjoint. Those at most two expanding nodes visit at most four children on the level below. Across $\ceil{\log_2 n} + 1$ levels, \textsc{Query} visits at most $4\ceil{\log_2 n} + 1 = \Oh(\log n)$ nodes.
\end{proof}

\begin{trapbox}
Two off-by-one and base-case bugs recur in segment tree code. First, the disjoint check must use strict inequalities, $qr < l$ or $r < ql$; writing $qr \le l$ drops index $l$ whenever $ql = qr = l$. Second, the disjoint return value must be the identity element of the chosen operation: $0$ for addition, $+\infty$ for $\min$, $-\infty$ for $\max$, $0$ for $\gcd$, and the identity matrix $\mathbf{I}$ for matrix products. Returning $0$ inside a range-minimum tree forces every query touching a disjoint branch to report $\le 0$.
\end{trapbox}

\subsection{Lazy propagation}

Adding $v$ to every entry in $a[ql\dots qr]$ leaf by leaf would cost $\Oh(n)$ time. \emph{Lazy propagation} restores $\Oh(\log n)$ range updates by storing a pending offset $\textit{lazy}[p]$ at each node $p$, recording an update already incorporated into $t[p]$ that has not yet been passed to $p$'s descendants. When a range-add covers $[l,r]$ completely, we add $(r - l + 1)\,v$ to $t[p]$, add $v$ to $\textit{lazy}[p]$, and return without recursing further. Later, whenever an update or query needs to descend into $p$'s children, it \emph{pushes} $\textit{lazy}[p]$ one level down to $2p$ and $2p+1$ and resets $\textit{lazy}[p] \gets 0$, as shown in Figure~\ref{ch42:fig-lazy-prop}. Because only partially overlapping nodes recurse, Theorem~\ref{ch42:thm-segtree} still bounds the number of visited nodes by $\Oh(\log n)$.

\begin{whybox}
Lazy propagation maintains the invariant that each node's cached sum $t[p]$ already reflects $\textit{lazy}[p]$ plus every ancestor's pushed updates, while $\textit{lazy}[p]$ records what is still owed strictly below $p$. Pushing $\textit{lazy}[p]$ to $2p$ and $2p+1$ \emph{before} recursing ensures no child is ever read or overwritten while an ancestor owes it an update.
\end{whybox}

\begin{complexitybox}
\textbf{Range structures.} Fenwick tree: $\Oh(\log n)$ update and prefix/range query, $\Oh(n)$ space, invertible operations only, smallest constant factor. Segment tree: $\Oh(n)$ build and space (array of size $4n$), $\Oh(\log n)$ query and point or lazy range update, works for any associative operation. Sparse table: precomputes answers on all power-of-two blocks in $\Oh(n\log n)$ time and space to answer static queries (no updates) in $\Oh(1)$ time for \emph{idempotent} operations -- those satisfying $x \oplus x = x$, such as $\min$, $\max$, and $\gcd$, where two overlapping blocks can cover $[l,r]$ without double-counting.
\end{complexitybox}

\begin{connectionbox}
Chapters~19--23 reduce tree problems to these array structures. Heavy-light decomposition (Chapter~19) and the Euler-tour technique (Chapter~21) flatten tree paths and subtrees into contiguous array intervals, then delegate updates and queries to a Fenwick or segment tree. Chapter~23 reduces lowest common ancestors to a range minimum query (RMQ) answered by a sparse table or segment tree, and link-cut trees (Chapter~22) maintain dynamic path aggregates when tree edges themselves are inserted and deleted.
\end{connectionbox}

\section{Linear Algebra for the Spectral Chapters}
\label{ch42:linalg}

Chapters~31--36 and~41 analyze graphs through symmetric matrices and their eigenvalues. This section collects the definitions and inequalities those chapters invoke; the companion \emph{Linear Algebra} volume develops the full proofs from scratch.

\subsection{Symmetric matrices and the spectral theorem}

Write $\R^n$ for the space of $n$-entry real column vectors $x = (x_1,\dots,x_n)^\top$, where the \emph{transpose} $(\cdot)^\top$ swaps rows and columns, giving dot product $x^\top y = \sum_{i=1}^n x_i y_i$ and Euclidean length $\norm{x} = \sqrt{x^\top x}$. An $n\times n$ real matrix $\mathbf{M} \in \R^{n\times n}$ is \emph{symmetric} if $\mathbf{M}^\top = \mathbf{M}$ (meaning $\mathbf{M}_{ij} = \mathbf{M}_{ji}$ for all $i,j$). A nonzero vector $x \in \R^n$ is an \emph{eigenvector} of $\mathbf{M}$ with \emph{eigenvalue} $\lambda$ if $\mathbf{M}x = \lambda x$: multiplying $x$ by $\mathbf{M}$ scales $x$ along its own line by factor $\lambda$ (reversing its direction when $\lambda < 0$ and sending it to $\mathbf{0}$ when $\lambda = 0$) instead of tilting it onto another line. The multiset of all eigenvalues of $\mathbf{M}$ is its \emph{spectrum}. Because undirected edges run both ways, adjacency matrices $\Adjm$ and graph Laplacians $\Lap$ of undirected graphs are symmetric, which guarantees real eigenvalues.

\begin{theorem}[Spectral theorem, real symmetric case]
\label{ch42:thm-spectral}
Every symmetric matrix $\mathbf{M} \in \R^{n\times n}$ has $n$ real eigenvalues
$\lambda_1 \le \lambda_2 \le \dots \le \lambda_n$ (listed with multiplicity, repeating an eigenvalue according to the dimension of its eigenspace) and an \emph{orthonormal basis} of eigenvectors $u_1, \dots, u_n \in \R^n$, meaning each has unit length ($\norm{u_i} = 1$) and any two are perpendicular ($u_i^\top u_j = 0$ for $i \ne j$). Equivalently,
\[
  \mathbf{M} = \sum_{i=1}^n \lambda_i\, u_i u_i^\top = \mathbf{U}\Lambda\mathbf{U}^\top,
\]
where $\mathbf{U} = [u_1\,\cdots\,u_n]$ is an orthogonal matrix ($\mathbf{U}^\top\mathbf{U} = \mathbf{I}$, with $\mathbf{I}$ the $n\times n$ identity matrix having $1$s on the main diagonal and $0$s elsewhere), $\Lambda = \diag(\lambda_1,\dots,\lambda_n)$ places $\lambda_1,\dots,\lambda_n$ on the main diagonal and $0$s off it, and each $u_i u_i^\top$ is the $n\times n$ outer-product matrix projecting onto $u_i$.
\end{theorem}

Whereas entries of $x$ in the \emph{standard basis} $e_1,\dots,e_n$ (where $e_k$ has $1$ in position $k$ and $0$ elsewhere) are mixed together by $\mathbf{M}$, expanding $x = \sum_{i=1}^n c_i u_i$ with $c_i = u_i^\top x$ turns $\mathbf{M}x = \sum_{i=1}^n \lambda_i c_i u_i$ into $n$ independent scalar multiplications, one per eigenvector axis.

\begin{intuitionbox}
View $\mathbf{M}$ as a linear deformation of $\R^n$, shown in Figure~\ref{ch42:fig-spectral-geometry}. Theorem~\ref{ch42:thm-spectral} states that a symmetric matrix has $n$ perpendicular principal axes $u_1,\dots,u_n$ along which it acts by pure scaling by $\lambda_i$, with no \emph{shear} (slanting distortion, like sliding a deck of cards sideways). For the graph Laplacian $\Lap = \mathbf{D} - \Adjm$, the smallest eigenvalue is $\lambda_1 = 0$ with eigenvector $\mathbf{1} = (1,\dots,1)^\top$, since $\Lap\mathbf{1} = \mathbf{0}$; the number of zero eigenvalues equals the number of connected components, and the second-smallest eigenvalue $\lambda_2$ (the \emph{Fiedler value}) measures how tightly connected the graph is across its narrowest bottleneck (Chapters~33 and~34).
\end{intuitionbox}

\subsection{Positive semidefiniteness and the Rayleigh quotient}

\begin{definition}[PSD and PD]
\label{ch42:def-psd}
A symmetric matrix $\mathbf{M} \in \R^{n\times n}$ is \emph{positive semidefinite} (PSD), written $\mathbf{M} \succeq 0$, if $x^\top\mathbf{M}x \ge 0$ for all $x \in \R^n$; it is \emph{positive definite} (PD), written $\mathbf{M} \succ 0$, if $x^\top\mathbf{M}x > 0$ for all nonzero $x \in \R^n$.
\end{definition}

\begin{proposition}[Equivalent characterizations of PSD]
\label{ch42:prop-psd}
For a symmetric matrix $\mathbf{M} \in \R^{n\times n}$, the following are equivalent: (i) $\mathbf{M} \succeq 0$; (ii) every eigenvalue satisfies $\lambda_i \ge 0$; (iii) $\mathbf{M} = \mathbf{B}^\top\mathbf{B}$ for some real matrix $\mathbf{B}$.
\end{proposition}

\begin{proof}
We verify the cycle of implications:
\begin{itemize}
\item $\text{(i)} \Rightarrow \text{(ii)}$: Evaluating $x^\top\mathbf{M}x \ge 0$ at unit eigenvector $x = u_i$ gives $u_i^\top(\lambda_i u_i) = \lambda_i \ge 0$.
\item $\text{(ii)} \Rightarrow \text{(iii)}$: Since $\lambda_i \ge 0$, define $\Lambda^{1/2} = \diag(\sqrt{\lambda_1},\dots,\sqrt{\lambda_n})$ and set $\mathbf{B} = \Lambda^{1/2}\mathbf{U}^\top$. Then $\mathbf{B}^\top\mathbf{B} = \mathbf{U}\Lambda^{1/2}\Lambda^{1/2}\mathbf{U}^\top = \mathbf{U}\Lambda\mathbf{U}^\top = \mathbf{M}$.
\item $\text{(iii)} \Rightarrow \text{(i)}$: For any $x \in \R^n$, $x^\top\mathbf{B}^\top\mathbf{B}x = (\mathbf{B}x)^\top(\mathbf{B}x) = \norm{\mathbf{B}x}^2 \ge 0$. \qedhere
\end{itemize}
\end{proof}

The primary example in this book is the graph Laplacian. Orienting each undirected edge $\{u,v\} \in E$ arbitrarily and stacking one row $(e_u - e_v)^\top \in \R^{1\times n}$ per edge forms the \emph{signed edge-vertex incidence matrix} $\mathbf{B} \in \R^{\abs{E}\times n}$ (placing $+1$ in column $u$, $-1$ in column $v$, and $0$ elsewhere). Multiplying $\mathbf{B}^\top\mathbf{B}$ gives
\[
  \Lap = \mathbf{B}^\top\mathbf{B} = \sum_{\{u,v\}\in E} (e_u - e_v)(e_u - e_v)^\top,
  \qquad
  x^\top \Lap x = \norm{\mathbf{B}x}^2 = \sum_{\{u,v\}\in E} (x_u - x_v)^2 \ge 0.
\]
Hence $\Lap \succeq 0$ for every unweighted (or nonnegative-weight) graph, and $x^\top \Lap x$ is the \emph{Dirichlet energy} minimized across Chapters~31, 33, 35, and~41. The vectors achieving $x^\top\Lap x = 0$ form the \emph{kernel} (or \emph{null space}) $\ker\Lap = \{x \in \R^n : \Lap x = \mathbf{0}\}$, consisting of vectors that are constant on every connected component.

\begin{definition}[Rayleigh quotient]
\label{ch42:def-rayleigh}
For symmetric $\mathbf{M} \in \R^{n\times n}$ and nonzero $x \in \R^n$, the \emph{Rayleigh quotient} is
\[
  R_{\mathbf{M}}(x) = \frac{x^\top\mathbf{M}x}{x^\top x}.
\]
\end{definition}

A $k$-dimensional \emph{subspace} $S \subseteq \R^n$ ($\dim S = k$) is the \emph{span} $\operatorname{span}\{v_1,\dots,v_k\}$ of $k$ linearly independent vectors -- the set of all linear combinations $a_1 v_1 + \dots + a_k v_k$ passing through the origin (a line for $k=1$, a plane for $k=2$).

\begin{theorem}[Variational characterization of eigenvalues]
\label{ch42:thm-courant}
Let $\mathbf{M} \in \R^{n\times n}$ be symmetric with eigenvalues $\lambda_1 \le \dots \le \lambda_n$. Then
\[
  \lambda_1 = \min_{x \ne \mathbf{0}} R_{\mathbf{M}}(x), \qquad
  \lambda_n = \max_{x \ne \mathbf{0}} R_{\mathbf{M}}(x),
\]
and more generally (the Courant--Fischer min-max theorem), for every $1 \le k \le n$,
\[
  \lambda_k = \min_{\dim S = k}\ \max_{\mathbf{0} \ne x \in S} R_{\mathbf{M}}(x).
\]
\end{theorem}

\begin{proof}
Expand $x = \sum_{i=1}^n c_i u_i$ in the orthonormal eigenbasis of Theorem~\ref{ch42:thm-spectral}. Orthonormality gives $x^\top x = \sum_{i=1}^n c_i^2$ and $x^\top\mathbf{M}x = \sum_{i=1}^n \lambda_i c_i^2$, so
\[
  R_{\mathbf{M}}(x) = \frac{\sum_{i=1}^n \lambda_i c_i^2}{\sum_{i=1}^n c_i^2}
\]
is a weighted average of $\lambda_1,\dots,\lambda_n$ with nonnegative weights $c_i^2 / \sum_j c_j^2$ summing to $1$. Any weighted average lies in $[\lambda_1, \lambda_n]$, attaining $\lambda_1$ at $x = u_1$ and $\lambda_n$ at $x = u_n$.

For Courant--Fischer, test $S_0 = \operatorname{span}\{u_1,\dots,u_k\}$: every nonzero $x \in S_0$ puts weight only on $\lambda_1,\dots,\lambda_k$, so $\max_{\mathbf{0} \ne x \in S_0} R_{\mathbf{M}}(x) = \lambda_k$ (attained at $u_k$), proving the minimum over $k$-dimensional subspaces is at most $\lambda_k$. Conversely, let $S$ be any subspace with $\dim S = k$, and set $U = \operatorname{span}\{u_k,\dots,u_n\}$, which has dimension $n - k + 1$. Because $\dim S + \dim U = n + 1 > n$ inside $\R^n$, $S$ and $U$ must share a nonzero vector $x_0 \in S \cap U$. Expanding $x_0$ uses only $u_k,\dots,u_n$, so $R_{\mathbf{M}}(x_0) \ge \lambda_k$, forcing $\max_{\mathbf{0} \ne x \in S} R_{\mathbf{M}}(x) \ge \lambda_k$.
\end{proof}

\begin{whybox}
Theorem~\ref{ch42:thm-courant} turns eigenvalue questions into optimization problems. Because $u_1 = \mathbf{1}/\sqrt{n}$ has eigenvalue $\lambda_1 = 0$ for $\Lap$, minimizing $R_{\Lap}(x)$ over nonzero vectors perpendicular to $\mathbf{1}$ gives
\[
  \lambda_2 = \min_{\substack{x \ne \mathbf{0} \\ \mathbf{1}^\top x = 0}} \frac{\sum_{\{u,v\}\in E} (x_u - x_v)^2}{\sum_{u\in V} x_u^2}.
\]
That continuous problem relaxes balanced graph partitioning: assign real coordinates $x_u$ centered at $0$ with unit total variance so that endpoints of edges stay close. On the \emph{normalized Laplacian} $\mathbf{D}^{-1/2}\Lap\mathbf{D}^{-1/2}$ (which rescales each vertex by $1/\sqrt{\deg(u)}$ and keeps all eigenvalues in $[0,2]$), Cheeger's inequality bounds cut \emph{conductance} -- cut edges divided by the smaller side's total degree -- between $\lambda_2/2$ and $\sqrt{2\lambda_2}$, explaining why thresholding the Fiedler vector finds sparse cuts.
\end{whybox}

\begin{example}[Trace and determinant from the spectrum]
\label{ch42:ex-trace}
The \emph{trace} $\tr(\mathbf{M}) = \sum_{i=1}^n \mathbf{M}_{ii}$ (the sum of the main-diagonal entries) and the \emph{determinant} $\det(\mathbf{M})$ (the signed volume scaling factor of $\mathbf{M}$, which equals $0$ if and only if $\mathbf{M}$ is not invertible) satisfy
\[
  \tr(\mathbf{M}) = \sum_{i=1}^n \lambda_i, \qquad
  \det(\mathbf{M}) = \prod_{i=1}^n \lambda_i.
\]
Applied to powers of the adjacency matrix, $(\Adjm^k)_{uu}$ counts closed walks of length $k$ from $u$ back to $u$, so $\tr(\Adjm^k) = \sum_{i=1}^n \lambda_i^k$ counts closed $k$-step walks via eigenvalues. Applied to $\Lap$, Kirchhoff's Matrix--Tree Theorem (Chapter~32) shows that an $n$-vertex graph has $\frac{1}{n}\prod_{i=2}^n \lambda_i$ spanning trees.
\end{example}

\begin{connectionbox}
Across the spectral chapters: Chapter~31 constructs $\Lap$ and proves that the number of connected components equals $\dim(\ker\Lap)$. Chapter~32 develops adjacency and Laplacian spectra and proves the Matrix--Tree Theorem. Chapter~33 clusters graphs by running $k$-means (grouping points in $\R^k$ around $k$ nearest centers) on the bottom eigenvectors of $\Lap$. Chapter~34 links $\lambda_2$ to expander graphs. Chapter~35 expresses effective electrical resistance through the \emph{Moore--Penrose pseudoinverse} $\Lap^+ = \sum_{\lambda_i > 0} \lambda_i^{-1} u_i u_i^\top$ (which inverts every nonzero eigenvalue along its eigenvector while sending $\ker\Lap$ to $\mathbf{0}$), and Chapter~41 solves $\Lap x = b$ to high accuracy in nearly linear time.
\end{connectionbox}

\section{Probability for the Randomized Chapters}
\label{ch42:probability}

Karger's minimum-cut contraction algorithm (Chapter~11), random walks and PageRank (Chapters~35--36), randomized rounding (Chapter~38), and graph streaming sketches (Chapter~40) rely on discrete probability: expected values, variance, union bounds, and tail concentration inequalities.

\subsection{Expectation, linearity, and variance}

A \emph{discrete random variable} $X$ assigns a number to the outcome of a random experiment, taking values $x$ from a finite or countable set with probabilities $\Pr[X = x]$. Its \emph{expectation} (or mean) is the probability-weighted average
\[
  \E[X] = \sum_x x\,\Pr[X = x].
\]
Random variables $X$ and $Y$ are \emph{independent} if learning one never alters the probabilities of the other: $\Pr[X = x \text{ and } Y = y] = \Pr[X = x]\,\Pr[Y = y]$ for all $x, y$. By contrast, \emph{linearity of expectation} holds for arbitrary random variables $X_1,\dots,X_k$ and constants $a_1,\dots,a_k$, whether the $X_i$ are independent or strongly correlated:
\[
  \E\!\left[\sum_{i=1}^k a_i X_i\right] = \sum_{i=1}^k a_i\,\E[X_i].
\]
Pairing linearity with \emph{indicator variables} -- setting $X_i = \mathbf{1}[A_i]$, which equals $1$ when event $A_i$ occurs and $0$ otherwise, so $\E[X_i] = 1\cdot\Pr[A_i] + 0\cdot(1-\Pr[A_i]) = \Pr[A_i]$ -- turns expected counts of complicated global structures into sums of single-event probabilities. Applying $\mathbf{1}[A_1 \cup \dots \cup A_k] \le \sum_{i=1}^k \mathbf{1}[A_i]$ and taking expectations also gives the \emph{union bound}:
\[
  \Pr[A_1 \cup \dots \cup A_k] \le \sum_{i=1}^k \Pr[A_i],
\]
again with no independence required.

\begin{example}[Indicator trick on random cuts]
\label{ch42:ex-indicator}
Form a \emph{uniformly random cut} $(S, V\setminus S)$ of an $m$-edge graph by placing each vertex independently into $S$ or $V\setminus S$ with probability $1/2$ each. For each edge $e = \{u,v\}$, let $X_e = \mathbf{1}[e \text{ crosses the cut}]$. Whatever side $u$ lands on, $v$ lands on the opposite side with probability $1/2$, so $\E[X_e] = 1/2$. Summing across all $m$ edges by linearity gives $\E\bigl[\sum_{e\in E} X_e\bigr] = m/2$, as illustrated in Figure~\ref{ch42:fig-random-cut}. Because a random variable cannot exceed its maximum value without at least one outcome reaching its mean, every $m$-edge graph has a cut of size at least $m/2$.
\end{example}

The \emph{variance} of $X$ measures the expected squared distance from its mean:
\[
  \Var[X] = \E\bigl[(X - \E[X])^2\bigr] = \E[X^2] - (\E[X])^2.
\]
When $X_1,\dots,X_k$ are pairwise independent, $\Var\bigl[\sum_{i=1}^k X_i\bigr] = \sum_{i=1}^k \Var[X_i]$. When they are dependent, one expands $\E\bigl[(\sum_{i=1}^k X_i)^2\bigr] = \sum_{i=1}^k \E[X_i^2] + \sum_{i \ne j} \E[X_i X_j]$ directly (Exercise~\ref{ch42:ex-perm-fixed}).

\subsection{Concentration: from average to almost-sure}

Expectation locates the center of a distribution; concentration inequalities bound the probability of landing far in the tails, turning average behavior into high-probability guarantees:

\begin{theorem}[Markov, Chebyshev, Chernoff]
\label{ch42:thm-concentration}
The following tail bounds hold in increasing order of assumption and strength (for the third bound, let $X = \sum_{i=1}^n X_i$ be a sum of independent $\{0,1\}$ variables with mean $\mu = \E[X]$):
\begin{align*}
  \Pr[X \ge t] &\le \frac{\E[X]}{t}
    && \text{\emph{(Markov: $X \ge 0$, $t > 0$)},} \\[3pt]
  \Pr\bigl[\,\abs{X - \E[X]} \ge t\,\bigr] &\le \frac{\Var[X]}{t^2}
    && \text{\emph{(Chebyshev: finite $\Var[X]$, $t > 0$)},} \\[3pt]
  \Pr\bigl[\,\abs{X - \mu} \ge \delta\mu\,\bigr] &\le 2\exp\!\left(-\frac{\delta^2\mu}{3}\right)
    && \text{\emph{(Chernoff: $0 < \delta \le 1$)}.}
\end{align*}
\end{theorem}

\begin{proof}
For Markov's inequality, since $X \ge 0$ and $t > 0$, dropping outcomes below $t$ and replacing $x \ge t$ by $t$ gives
\begin{align*}
  \E[X] = \sum_{x \ge 0} x\,\Pr[X = x]
  &\ge \sum_{x \ge t} x\,\Pr[X = x] \\
  &\ge t \sum_{x \ge t} \Pr[X = x] = t\,\Pr[X \ge t],
\end{align*}
and dividing by $t$ proves the first bound. Chebyshev's inequality applies Markov's inequality to the nonnegative variable $Y = (X - \E[X])^2$ at threshold $t^2$, since $\abs{X - \E[X]} \ge t \iff Y \ge t^2$. The Chernoff bound applies Markov's inequality to the positive variable $e^{sX}$ for a tunable parameter $s > 0$: its expectation $\E[e^{sX}]$ (the \emph{moment generating function} of $X$) factors by independence into $\prod_{i=1}^n \E[e^{sX_i}]$, and minimizing the resulting bound over $s$ produces the $\exp(-\delta^2\mu/3)$ upper tail (and symmetrically the lower tail via $e^{-sX}$).
\end{proof}

\begin{intuitionbox}
Figure~\ref{ch42:fig-tail-bounds} compares the three decay rates. Markov's inequality assumes only $X \ge 0$ and shrinks at rate $1/k$. Chebyshev's inequality uses $\Var[X]$ to shrink at rate $1/k^2$, which powers the \emph{median trick}: taking the median of $\Oh(\log(1/\eps))$ independent Chebyshev-accurate estimates fails only when at least half of them err simultaneously, driving failure probability down to $\eps$. Chernoff's bound uses full independence to shrink \emph{exponentially}, so repeating a $2/3$-accurate randomized algorithm $\Oh(k)$ times and taking a majority vote reduces error below $2^{-k}$.
\end{intuitionbox}

\begin{applicationbox}
One run of Karger's algorithm (Chapter~11) contracts random edges until two supernodes remain; a fixed minimum cut survives all $n-2$ contractions with probability at least $2/(n(n-1)) > 2/n^2$ (Exercise~\ref{ch42:ex-karger-warmup}). Repeating the contraction $\ceil{\tfrac{1}{2}n^2\ln n}$ independent times and keeping the smallest cut found drives the probability of missing a fixed minimum cut down to at most $(1 - 2/n^2)^{(n^2\ln n)/2} \le e^{-\ln n} = 1/n$, using $1 - x \le e^{-x}$. Chapters~35 and~36 connect probability back to Section~\ref{ch42:linalg} when bounding random-walk \emph{mixing times} -- the number of steps needed for walk probabilities to approach the long-run \emph{stationary distribution} $\pi$ satisfying $\mathbf{P}^\top\pi = \pi$ -- via the spectral gap $1 - \lambda_2$ of the walk's transition matrix $\mathbf{P}$ (where $\lambda_2$ here denotes its second-largest eigenvalue).
\end{applicationbox}

\begin{trapbox}
Chernoff's bound requires independence across summands. Linearity of expectation holds under arbitrary dependence, whereas variance addition and exponential tail concentration do not: if $X_1 = X_2 = \dots = X_n$ all flip the \emph{same} fair coin, $\E[\sum X_i] = n/2$, yet the sum equals $0$ or $n$ with probability $1/2$ each rather than concentrating near $n/2$. Before applying Chernoff, verify that the indicator variables are mutually independent (or negatively correlated); when steps depend on past choices, use bounded-difference tools such as Azuma's inequality for martingales (step-by-step random processes whose conditional expected step change is zero).
\end{trapbox}

\section{Historical Context, Controversies, and the Unified Curriculum}

\begin{historybox}
Each tool in this appendix arose to solve a concrete bottleneck in calculation, data layout, or physical modeling. Asymptotic notation began with Paul Bachmann (1894) and Edmund Landau in analytic number theory before Donald Knuth standardized $\Oh$, $\Om$, and $\Th$ for computer science in 1976. Disjoint-set union, introduced by Bernard Galler and Michael Fischer in 1964 for equivalence declarations in compilers, resisted tight runtime analysis for a decade. Researchers split between conjecturing $\Oh(1)$ amortized cost and suspecting an $\Om(\log\log n)$ barrier until Robert Tarjan proved in 1975 that $m$ operations on $n$ items take $\Th(m\,\alpha(m,n))$ time (bounded by $\Oh(m\,\alpha(n))$), showing that the true growth rate is non-constant yet slower than any finite composition of polynomials, exponentials, and logarithms (\emph{elementary functions}). Priority queues developed over the same period: J.~W.~J.~Williams introduced the binary heap for heapsort in 1964, Robert Floyd published the $\Oh(n)$ bottom-up build later that year, and Michael Fredman and Robert Tarjan (1984) designed Fibonacci heaps -- using potential functions to pay for detaching damaged subtrees -- to bring Dijkstra's algorithm down to $\Oh(m + n\log n)$ time.

Range data structures grew out of computational geometry and compression. In 1977, Jon Bentley introduced segment trees to solve Klee's measure problem (computing the total length or area covered by a union of overlapping intervals or rectangles) by decomposing intervals into $\Oh(\log n)$ power-of-two-aligned (\emph{dyadic}) blocks. In 1994, Peter Fenwick invented the binary indexed tree to maintain cumulative symbol frequencies for arithmetic data compression (which encodes messages into narrow subintervals of $[0,1)$), exploiting two's-complement bit arithmetic to eliminate child pointers. The variational view of eigenvalues dates back to Ernst Fischer (1905) and Richard Courant (1920), who formulated Theorem~\ref{ch42:thm-courant} to study vibrating membranes and differential operators.

On the randomized spectral frontier, early analyses of random graph matrices applied scalar Chernoff bounds entry by entry and combined all $n^2$ entries via a union bound, losing large dimensional factors because matrix multiplication is \emph{non-commutative} ($\mathbf{A}\mathbf{B} \ne \mathbf{B}\mathbf{A}$). Beginning with Rudolf Ahlswede and Andreas Winter (2002) and consolidated by Joel Tropp (2012), matrix concentration inequalities generalized moment generating functions to symmetric matrices, directly powering randomized graph sparsifiers and fast Laplacian solvers (Chapter~41). Designing pointer-free dynamic range structures that match theoretical bounds while staying \emph{cache-oblivious} (running efficiently across all CPU cache block sizes without hardware-specific tuning) remains an active research direction.
\end{historybox}

\subsection{Summary of the Book and Companion Volumes}
\begin{connectionbox}
\textbf{What This Book Has Built}:
Across forty-one main chapters and this appendix, the book has developed five connected layers of graph algorithms:
\begin{enumerate}
  \item \emph{Discrete Foundations}: Graph representations, breadth-first and depth-first search (BFS, DFS), topological sorting, strongly connected components, minimum spanning trees, and shortest paths (Dijkstra, Bellman--Ford).
  \item \emph{Combinatorial Optimization and Tree Structures}: Maximum flows, minimum cuts, bipartite and general matchings, heavy-light decomposition, Euler-tour flattening, and link-cut trees.
  \item \emph{NP-Hardness and Approximation}: Polynomial-time reductions, Christofides' approximation for the metric traveling salesman problem (TSP), and Goemans--Williamson semidefinite rounding (mapping vertices to unit vectors and slicing them with a random hyperplane through the origin).
  \item \emph{Dynamic and Streaming Algorithms}: Online forest and connectivity maintenance via Holm--de~Lichtenberg--Thorup (HdLT) level hierarchies, and sublinear-space connectivity via Ahn--Guha--McGregor (AGM) linear sketches.
  \item \emph{Continuous and Spectral Methods}: The graph Laplacian $\Lap$, Cheeger's inequality, spectral clustering, random-walk and resistor-network duality, and nearly linear-time Laplacian solvers.

\section{Exercises}
\label{ch42:exercises}

\begin{exercise}[Asymptotic sorting]
Order these functions from slowest to fastest asymptotic growth, grouping any that are $\Th$ of each other:
$n\log n$, $2^{\log_2 n}$, $n^{1/\log_2 n}$, $\log(n!)$, $n^{1.001}$, $(\log n)^{\log n}$,
$2^{\sqrt{\log n}}$. (Hint: Stirling's approximation $n! \approx \sqrt{2\pi n}\,(n/e)^n$ implies $\log(n!) = \Th(n\log n)$, and taking $\log_2$ shows $n^{1/\log_2 n} = 2$.)
\end{exercise}

\begin{exercise}[Potential method]
A stack supports \textsc{Push}, \textsc{Pop}, and \textsc{MultiPop}$(k)$, which pops $\min(k, \text{size})$ elements in $\min(k, \text{size})$ steps. Using the potential $\Phi(D) = \text{size}$, prove that every operation has $\Oh(1)$ amortized cost, so any sequence of $n$ operations starting from an empty stack runs in $\Oh(n)$ total time.
\end{exercise}

\begin{exercise}[Union-find lower bound by example]
Show that \emph{without} union by rank, path compression alone allows a single $\find$ to take $\Om(n)$ steps: construct a sequence of $n-1$ unions that builds a chain of height $n-1$, then identify the $\Om(n)$-step $\find$. Contrast this with union by rank alone (no path compression), which keeps every individual $\find$ within $\Oh(\log n)$ worst-case time by Lemma~\ref{ch42:lem-rank}.
\end{exercise}

\begin{exercise}[Heapify is tight]
Prove that bottom-up \textsc{Heapify} takes $\Th(n)$ time in the worst case, not $o(n)$: construct an $n$-element input array on which bottom-up \textsc{SiftDown} performs $\Om(n)$ swaps. Then give an $n$-element input sequence on which top-down heap construction ($n$ calls to \textsc{Insert}) performs $\Th(n\log n)$ swaps.
\end{exercise}

\begin{exercise}[Fenwick from scratch]
\label{ch42:ex-fenwick-range}
Support range-add, $a[l\dots r] \mathrel{+}= v$, and range-sum, $\sum_{j=l}^r a[j]$, using two Fenwick trees $B_1, B_2$ built over the difference array $d[k] = a[k] - a[k-1]$ (with $a[0]=0$), where $B_1$ stores $d[k]$ and $B_2$ stores $k \cdot d[k]$. Prove the prefix-sum identity
\[
  \sum_{j=1}^i a[j] = (i+1)\cdot B_1.\textsc{PrefixSum}(i) - B_2.\textsc{PrefixSum}(i),
\]
and verify it by hand on $n=4$ after one range-add operation.
\end{exercise}

\begin{exercise}[Segment tree, non-sum aggregate]
Adapt Algorithm~4 in Section~\ref{ch42:segtree} to answer range-\emph{minimum} queries with point updates. State the disjoint-branch identity element, write the node-combine step, and trace $\min a[2\dots 7]$ on $a = [3,4,1,4,6,3,5,3]$, listing the cached node intervals combined by the query.
\end{exercise}

\begin{exercise}[Break the lazy tag]
Consider a buggy lazy segment tree for range-add and range-sum that pushes a node's lazy tag to its children \emph{after} the recursive calls return rather than before descending. Construct a sequence of two overlapping range-adds and one range-sum query that returns an incorrect sum, and state which invariant from Section~\ref{ch42:segtree} the reversed order violates.
\end{exercise}

\begin{exercise}[Rayleigh quotient by hand]
Consider the symmetric $2\times 2$ matrix
\[
  \mathbf{M} = \begin{pmatrix} 2 & 1 \\ 1 & 2 \end{pmatrix}.
\]
Compute its eigenvalues $\lambda_1 \le \lambda_2$ and an orthonormal basis of eigenvectors. Verify Theorem~\ref{ch42:thm-courant} by evaluating $R_{\mathbf{M}}(x)$ at $x = (1,0)^\top$, $x = (1,1)^\top$, and $x = (1,-1)^\top$, checking that each value lies in $[\lambda_1, \lambda_2]$ with equality at the eigenvectors.
\end{exercise}

\begin{exercise}[Laplacian is PSD]
For the three-vertex path graph $1$--$2$--$3$, write down $\Lap \in \R^{3\times 3}$ explicitly, exhibit the $2\times 3$ signed incidence matrix $\mathbf{B}$ satisfying $\Lap = \mathbf{B}^\top\mathbf{B}$, and verify that $x^\top\Lap x = (x_1 - x_2)^2 + (x_2 - x_3)^2 \ge 0$. Find a basis for $\ker\Lap$ and check that $\dim(\ker\Lap)$ matches the number of connected components.
\end{exercise}

\begin{exercise}[Indicator trick]
\label{ch42:ex-perm-fixed}
A uniformly random permutation of $\{1,\dots,n\}$ (all $n!$ reorderings equally likely) has a \emph{fixed point} at $i$ if it maps $i \mapsto i$. Using indicator variables and linearity of expectation, prove that the expected number of fixed points is $1$ for every $n \ge 1$. Then compute the variance by expanding $\E\bigl[(\sum_{i=1}^n X_i)^2\bigr]$ (note that $X_i$ and $X_j$ are not independent) and apply Chebyshev's inequality to bound the probability of seeing at least $t$ fixed points for $t > 1$.
\end{exercise}

\begin{exercise}[Boosting by repetition]
A \emph{Monte Carlo algorithm} (a randomized algorithm with fixed runtime whose output can err with bounded probability) answers correctly with probability $2/3$ on every input. Suppose you run it $2k+1$ independent times and return the majority answer. Using the Chernoff bound of Theorem~\ref{ch42:thm-concentration}, show that the majority vote errs with probability at most $2e^{-\Om(k)}$, and determine $k = \Th(\log n)$ so that the error probability drops below $1/n$.
\end{exercise}

\begin{exercise}[Karger survival, warm-up]
\label{ch42:ex-karger-warmup}
In a multigraph whose minimum cut has $c$ edges, every vertex has degree at least $c$, so $m \ge nc/2$. Show that a uniformly random edge avoids a fixed minimum cut with probability at least $1 - 2/n$. Conditioning step by step across $n-2$ contractions as the vertex count drops from $n$ down to $3$, telescope the product $\prod_{r=3}^n (1 - 2/r)$ to derive the $\ge 2/(n(n-1))$ survival probability stated in Section~\ref{ch42:probability}.
\end{exercise}
