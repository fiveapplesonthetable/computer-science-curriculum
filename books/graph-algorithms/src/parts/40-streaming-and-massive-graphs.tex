\chapter{Streaming and Massive Graphs}
\label{ch:streaming}

In Chapter~39, we maintained connectivity and trees as edges were inserted
and deleted, assuming the active graph could always fit in memory.
That assumption fails once the graph is a web crawl with $10^{11}$ edges,
a social network arriving as a continuous feed of friend events, or a router log
streaming past faster than any disk can store it. In those settings the graph never
sits in memory all at once: we see edges one at a time in an order we cannot
choose, and our working memory is a tiny fraction of the input size.
What can we still compute about a graph when we only have room to store a few
numbers per vertex --- and which problems provably require storing almost every edge?

\chapterline

\section{The streaming model}
\label{ch40:model}

\begin{definition}[Graph stream]\label{ch40:def-stream}
Let $\Gph=(V,E)$ have $n=\abs{V}$ vertices, known in advance and labeled
$1,\dots,n$. A \emph{graph stream} is a sequence
$\sigma = \langle a_1, a_2, \dots, a_m\rangle$ of items, called \emph{tokens},
presented one at a time. In the \emph{insertion-only} (or \emph{cash-register},
where counts only go up) model, each token $a_i$ is an edge $\set{u,v}$ to be
added. In the \emph{dynamic} (or \emph{turnstile}, like a subway gate counting
entries and exits) model, each token is a pair $(\set{u,v}, \Delta)$ with
$\Delta \in \set{+1,-1}$, where $+1$ inserts $\set{u,v}$ and $-1$ deletes a
previously inserted copy. An algorithm reads tokens from left to right, keeps a
working memory state $S$ of bounded size, and updates $S$ after each token.
After the last token $a_m$, it answers a query about the resulting graph $\Gph$.
\end{definition}

Three quantities measure the cost of a streaming algorithm:

\begin{itemize}
\item \textbf{Space} $s$: the number of bits of working memory kept between
tokens. Reading the current token $a_i$ does not count against $s$; only what
we retain in $S$ does.
\item \textbf{Passes} $p$: how many times we scan $\sigma$ from $a_1$ to $a_m$.
The default and strictest setting is a single pass ($p=1$).
\item \textbf{Update time} (work per token) and \textbf{post-processing time}
(work at the end of the stream to compute the answer from $S$).
\end{itemize}

A simple graph on $n$ vertices can have up to $\binom{n}{2}=n(n-1)/2=\Th(n^2)$
edges, and a dynamic stream can contain $m$ tokens with $m$ even larger. Our
goal is to use space $s$ much smaller than the edge count ($s \ll m$).

\begin{definition}[Semi-streaming]\label{ch40:def-semistream}
A streaming algorithm is \emph{semi-streaming} if it uses
$\Oh(n\,\poly\log n)$ bits of space --- that is, $\Oh(n\log^c n)$ bits for some
fixed constant $c \ge 0$ --- and a small number of passes (ideally $p=1$).
\end{definition}

\begin{intuitionbox}
Why $n\,\poly\log n$ bits rather than $\sqrt{n}$ or $n^{1.5}$? Because naming a
single vertex in $\set{1,\dots,n}$ takes $\ceil{\log_2 n}$ bits (one
$\Th(\log n)$-bit machine word), so $\Oh(n\log n)$ bits is enough to store a
constant number of vertex identifiers per vertex. Below $n$ bits you cannot even
record which vertices lie in the same connected component
(Theorem~\ref{ch40:thm-lb-conn}); at $n^{1+c}$ bits (for a constant $0<c<1$) you
can store $n^c$ incident edges per vertex. Semi-streaming sits at the boundary
where vertices fit in memory and edges do not, as Figure~\ref{ch40:fig-regimes}
illustrates.
\end{intuitionbox}

\section{Connectivity in one pass}
\label{ch40:connectivity}

The simplest semi-streaming result decides whether $\Gph$ is connected (and
in fact maintains its connected components) in one pass and $\Oh(n\log n)$
bits.

\begin{intuitionbox}
A spanning forest already tells you the components, and a forest on $n$
vertices has at most $n-1$ edges. So we never need to store more than $n-1$
edges. Maintain a forest incrementally: when an edge $\set{u,v}$ arrives, add
it only if $u$ and $v$ are not already connected by what we have kept ---
otherwise it would close a cycle and is useless for connectivity. That is
exactly Kruskal's forest-building, run online, with a union--find structure
deciding ``already connected?'' in near-constant amortized time.
\end{intuitionbox}

\begin{algorithm}[H]
\caption{\textsc{StreamingSpanningForest}}
\label{ch40:alg-forest}
\DontPrintSemicolon
\KwIn{vertex set $V=\set{1,\dots,n}$; insertion stream of edges}
\KwOut{a spanning forest $F$; component labels}
initialize union--find $\mathcal{D}$ with each $v$ in its own set\;
$F \gets \emptyset$\;
\ForEach{arriving edge $\set{u,v}$}{
  \If{$\textsc{Find}(u)\neq\textsc{Find}(v)$}{
    $F \gets F \cup \set{\set{u,v}}$\;
    $\textsc{Union}(u,v)$\;
  }
}
\Return $F$ and the \textsc{Find} labels\;
\end{algorithm}

\begin{whybox}
\textbf{Correctness.} We prove by induction on the number of tokens read that
$F$ is always a spanning forest of the graph seen so far, with the same
connected components. Before the first token, both the seen graph and $F$ have
$n$ isolated vertices and no edges. When $\set{u,v}$ arrives, there are two
cases. If $u$ and $v$ already lie in the same tree of $F$, then by the
induction hypothesis they are already connected in the seen graph, so the new
edge merges no components and skipping it keeps $F$ a spanning forest of the
same partition. If $u$ and $v$ lie in different trees of $F$, the seen graph
merges their two components, and adding $\set{u,v}$ joins those two trees
without creating a cycle. Thus $F$ remains a spanning forest with the same
connected components after every token. At stream end, $\Gph$ is connected if
and only if $F$ is a single tree, that is, $\abs{F}=n-1$.
\end{whybox}

\begin{complexitybox}
$F$ holds at most $n-1$ edges, each stored as two $\ceil{\log_2 n}$-bit vertex
labels, taking $\Oh(n\log n)$ bits; the union--find parent and rank arrays add
another $\Oh(n\log n)$ bits. Total space is $\Oh(n\log n)$ bits in one pass.
Per-token work is one \textsc{Find}/\textsc{Union} pair, costing
$\Oh(\alpha(n))$ amortized time with path compression and union by rank
(where $\alpha(n)$ is the inverse Ackermann function from Chapter~6).
Post-processing takes $\Oh(n)$ time.
\end{complexitybox}

\subsection{Bipartiteness and \texorpdfstring{$k$}{k}-edge-connectivity}

Keeping a constant or small multiple of the forest space answers richer
connectivity questions in one pass, as illustrated in
Figure~\ref{ch40:fig-bipartite-kforest}.

\textbf{Bipartiteness.} Store the spanning forest $F$ together with one parity
bit $\phi(v)\in\set{0,1}$ per vertex, recording a valid $2$-coloring of each
tree in $F$. When an edge $\set{u,v}$ merges two distinct trees and happens to
have $\phi(u)=\phi(v)$, flip $\phi$ across the smaller tree so that $u$ and $v$
get opposite colors (each vertex sits in the smaller half of a merge at most
$\log_2 n$ times, or the flip can be stored lazily along union--find parent
pointers). When a non-tree edge $\set{u,v}$ arrives with
$\textsc{Find}(u)=\textsc{Find}(v)$, check whether $\phi(u)=\phi(v)$: equal
colors mean the unique tree path between $u$ and $v$ has even length, so
$\set{u,v}$ closes an odd cycle and $\Gph$ is not bipartite. This uses one pass
and $\Oh(n\log n)$ bits.

\textbf{$k$-edge-connectivity.} A graph is \emph{$k$-edge-connected} if it
remains connected after deleting any $k-1$ edges --- equivalently, every
nontrivial cut $(S,\bar S)$ has at least $k$ crossing edges (generalizing
$2$-edge-connectivity from Chapter~10). To test this in one pass, maintain $k$
edge-disjoint spanning forests $F_1,\dots,F_k$ online (the Nagamochi--Ibaraki
sparsification rule): insert each arriving edge $\set{u,v}$ into the first
forest $F_i$ in which $u$ and $v$ are not yet connected, and drop $\set{u,v}$
only if all $k$ forests reject it. Why is dropping safe? If $\set{u,v}$ crosses
a cut $(S,\bar S)$ and every $F_i$ rejects it, then each $F_i$ already contains
a $u$--$v$ path and therefore at least one edge crossing $(S,\bar S)$. Because
$F_1,\dots,F_k$ are pairwise edge-disjoint, the union $F_1\cup\cdots\cup F_k$
already holds at least $k$ distinct crossing edges. Consequently every cut of
size at most $k$ in $\Gph$ survives intact in $F_1\cup\cdots\cup F_k$, answering
$k$-edge-connectivity in $\Oh(kn\log n)$ bits (semi-streaming whenever
$k=\poly\log n$).

\begin{connectionbox}
The forest trick is Kruskal (Chapter~6) without sorting: the stream supplies
an arbitrary order and we keep whatever extends the forest. The $k$-forest
sparsifier is the combinatorial counterpart of the \emph{spectral} sparsifier previewed in
Chapter~35 and developed in Chapter~41: there we preserve every quadratic form $x^\top\Lap x$ to
within $1\pm\eps$ using $\Oh(n\log n/\eps^2)$ \emph{weighted} edges; here we
preserve every cut of value $\le k$ exactly using $kn$ \emph{unweighted}
edges. Both make the same point: a graph's connectivity structure is
compressible to near-linear size.
\end{connectionbox}

\section{Spanners: approximate distances in small space}
\label{ch40:spanners}

A spanning forest forgets distances: dropping a single edge of an $n$-cycle
turns a length-$1$ step into a length-$(n-1)$ detour. To preserve approximate
shortest-path distances in one pass, we maintain a \emph{spanner}.

\begin{definition}[Spanner]\label{ch40:def-spanner}
Let $\Gph=(V,E)$ be a graph and let $t \ge 1$. A spanning subgraph
$H=(V,E_H)$ with $E_H \subseteq E$ is a \emph{$t$-spanner} of $\Gph$ (with
multiplicative \emph{stretch} $t$) if for all $u,v\in V$,
\[
\dist_\Gph(u,v) \;\le\; \dist_H(u,v) \;\le\; t\cdot \dist_\Gph(u,v).
\]
\end{definition}

Because $H$ contains a subset of the edges of $\Gph$, paths in $H$ are never
shorter than in $\Gph$, so the lower bound $\dist_\Gph(u,v) \le \dist_H(u,v)$
holds automatically. For the upper bound, checking edges is enough: if
$\dist_H(x,y) \le t$ for every edge $\set{x,y}\in E$, then replacing each edge
along a shortest $u$--$v$ path in $\Gph$ with its detour of length at most $t$
in $H$ yields a walk in $H$ of length at most $t\cdot \dist_\Gph(u,v)$. A
streaming algorithm therefore only needs to ensure that whenever it drops an
arriving edge $\set{u,v}$, $H$ already connects $u$ and $v$ within distance $t$.

\begin{intuitionbox}
Build the spanner greedily online: when $\set{u,v}$ arrives, ask ``are $u$ and
$v$ already within distance $t$ using the edges kept so far?'' If yes, drop
$\set{u,v}$; if no, keep it. Keeping it whenever $\dist_H(u,v)>t$ guarantees
stretch $t$. Dropping it whenever $\dist_H(u,v)\le t$ guarantees that $H$ has
large \emph{girth} (the length of its shortest cycle): every cycle in $H$ has
length strictly greater than $t+1$, because the last edge of any shorter cycle
would have seen its endpoints within distance $t$ and been dropped. Large girth
in turn forces $H$ to be sparse.
\end{intuitionbox}

Writing odd stretch values as $t = 2k-1$ for an integer $k \ge 1$ pairs cleanly
with cycle lengths: $k=1$ gives $t=1$ (keep every edge, no approximation),
$k=2$ gives $t=3$ (forbid triangles and $4$-cycles), and general $k$ forbids
cycles of length at most $2k$.

\begin{algorithm}[H]
\caption{\textsc{StreamingGreedySpanner}$(t)$, for odd $t=2k-1$}
\label{ch40:alg-spanner}
\DontPrintSemicolon
\KwIn{insertion stream of edges on $V$; integer $k\ge 1$ setting stretch $t=2k-1$}
\KwOut{a $(2k-1)$-spanner $H=(V,E_H)$}
$E_H \gets \emptyset$\;
\ForEach{arriving edge $\set{u,v}$}{
  compute $d \gets \dist_H(u,v)$ by BFS in $H$ (stopping early past depth $t$)\;
  \tcp{$d = \infty > t$ when $u$ and $v$ lie in different components of $H$}
  \If{$d > t$}{
    $E_H \gets E_H \cup \set{\set{u,v}}$\;
  }
}
\Return $H=(V,E_H)$\;
\end{algorithm}

\begin{whybox}
\textbf{Stretch.} Every kept edge has $\dist_H(u,v) = 1 \le t$. Every dropped
edge $\set{u,v}$ had $\dist_H(u,v) \le t$ when it arrived, and adding later
edges to $H$ can only decrease distances. Hence $\dist_H(u,v) \le t$ holds for
every $\set{u,v}\in E$ at the end of the stream, making $H$ a $t$-spanner.

\textbf{Sparsity via girth.} Suppose for contradiction that $H$ contains a
cycle $C$ of length $\ell \le t+1 = 2k$, and let $\set{u,v}$ be the last edge
of $C$ added to $H$. Just before $\set{u,v}$ arrived, the remaining $\ell-1$
edges of $C$ were already in $H$, forming a $u$--$v$ path of length
$\ell-1 \le t$. Thus $\dist_H(u,v) \le t$, and Algorithm~\ref{ch40:alg-spanner}
would have dropped $\set{u,v}$. Therefore $H$ has girth at least $t+2 = 2k+1$.
\end{whybox}

\begin{lemma}[High-girth graphs are sparse: the Moore bound]\label{ch40:lem-moore}
Every graph on $n$ vertices with girth at least $2k+1$ has $\Oh(n^{1+1/k})$
edges.
\end{lemma}

\begin{proof}[Proof sketch]
Let $m=\abs{E}$ and let $d = 2m/n$ be the average degree. If $d \le 4$, then
$m \le 2n \le 2n^{1+1/k}$ immediately, so assume $d > 4$. Repeatedly delete any
vertex whose current degree is strictly less than $d/2$. At most $n$ vertices
can be deleted, removing fewer than $n\cdot (d/2) = m$ edges in total, so the
deletion process must stop at a nonempty subgraph $\Gph'$ in which every
surviving vertex has degree at least $\delta = \ceil{d/2} \ge d/2$.

Pick any root $r \in V(\Gph')$ and grow a BFS tree in $\Gph'$ to depth $k$
(Figure~\ref{ch40:fig-moore}, Panel~A). If two distinct walks of length at most
$k$ from $r$ without immediate backtracking met at the same vertex, their union
would contain a cycle of length at most $2k$, contradicting girth $\ge 2k+1$.
The first $k$ BFS layers therefore branch without ever colliding: $r$ has at
least $\delta$ neighbors, and each vertex at depths $1,\dots,k-1$ has at least
$\delta - 1 \ge d/4$ children (all of its $\ge \delta$ neighbors except its
single BFS parent). Layer $k$ alone contains at least $\delta(\delta-1)^{k-1}
\ge (d/4)^k$ distinct vertices of $\Gph'$, so
\[
  \Bigl(\frac{d}{4}\Bigr)^{\!k} \;\le\; \abs{V(\Gph')} \;\le\; n
  \qquad\Longrightarrow\qquad
  d \;\le\; 4\,n^{1/k},
  \qquad\Longrightarrow\qquad
  m \;=\; \frac{nd}{2} \;\le\; 2\,n^{1+1/k}. \qedhere
\]
\end{proof}

Algorithm~\ref{ch40:alg-spanner} with $t=2k-1$ maintains a $(2k-1)$-spanner of

\end{complexitybox}

\begin{trapbox}
``Isn't a spanning forest already a spanner?'' Only with worst-case stretch $n-1$:
deleting a single edge of an $n$-cycle leaves a spanning path whose endpoints
jump from distance $1$ to distance $n-1$. A spanning forest preserves
\emph{connectivity} in $n-1$ edges, whereas preserving \emph{distances} within
multiplicative stretch $2k-1$ requires keeping extra cycle edges and paying the
$\Oh(n^{1+1/k})$ space trade-off of Lemma~\ref{ch40:lem-moore}.
\end{trapbox}

\section{Dynamic streams: when edges get deleted}
\label{ch40:sketching}

Algorithms~\ref{ch40:alg-forest} and~\ref{ch40:alg-spanner} fail
under deletions. Suppose the spanning forest keeps edge $\set{u,v}$, and later a
token $\bigl(\set{u,v},-1\bigr)$ deletes it: the forest does not know
which remaining edge could reconnect the two halves, because it threw
cycle-closing edges away when they arrived. Greedy retention cannot be undone.

The fix is to store, instead of a chosen subset of edges, a small
\emph{linear} summary $\mathsf{Sk}(x)$ of an edge-indicator vector $x$. A map
$\mathsf{Sk}$ is linear if $\mathsf{Sk}(x+y)=\mathsf{Sk}(x)+\mathsf{Sk}(y)$ and
$\mathsf{Sk}(cx)=c\,\mathsf{Sk}(x)$. Linearity handles deletions automatically:
an insertion adds $\mathsf{Sk}(e)$ and a deletion subtracts $\mathsf{Sk}(e)$,
canceling the inserted copy without remembering individual edges.

\begin{recoverybox}
\textbf{Pause and think}: Why does deleting an edge break a greedy forest? In an insertion stream, discarding a cycle-closing edge is safe because the kept tree already connects its endpoints. Once a tree edge is deleted, however, the tree splits into two components, and any replacement edge that arrived earlier was already discarded.
\end{recoverybox}

Figure~\ref{ch40:fig-greedy-delete} traces this failure mode on the triangle $\set{1,2,4}$ from the running graph: once the cycle-closing edge $(1,4)$ is discarded, a later deletion of the tree edge $(2,4)$ leaves the forest disconnected even though $(1,4)$ still bridges the cut in $\Gph$.

\subsection{The vertex--edge incidence vector}

Let $\binom{V}{2}$ denote the set of all $\binom{n}{2}=n(n-1)/2$ unordered
vertex pairs $\set{u,w}$ with $u < w$. Index $\R^{\binom{n}{2}}$ by these
pairs. For each vertex $v \in V$, define its \emph{signed incidence vector}
$x_v \in \R^{\binom{n}{2}}$ on every pair $\set{u,w}$ ($u < w$) by
\[
  (x_v)_{\set{u,w}} \;=\;
  \begin{cases}
    +1 & \text{if } \set{u,w}\in E \text{ and } v = u,\\
    -1 & \text{if } \set{u,w}\in E \text{ and } v = w,\\
    0  & \text{otherwise.}
  \end{cases}
\]
Thus each present edge $\set{u,w}$ ($u<w$) puts $+1$ at its smaller endpoint's
vector $x_u$ and $-1$ at its larger endpoint's vector $x_w$, while absent edges
and non-incident pairs have entry $0$. For any vector $z$, write its
\emph{support} $\operatorname{supp}(z) = \set{i : z_i \neq 0}$ for the set of
coordinates where $z$ is nonzero.

\begin{lemma}[Boundary cancellation]\label{ch40:lem-boundary}
For any vertex subset $S\subseteq V$ with complement $\bar S = V\setminus S$,
the support $\operatorname{supp}\!\bigl(\sum_{v\in S} x_v\bigr)$ is the set of
edges crossing the cut $(S,\bar S)$.
\end{lemma}

\begin{proof}
Fix a coordinate $\set{u,w}$ with $u < w$. Only $x_u$ and $x_w$ can have a
nonzero entry at $\set{u,w}$, and only when $\set{u,w}\in E$. If both
$u,w\in S$, their entries $+1$ and $-1$ cancel to $0$. If neither lies in $S$,
neither contributes. If one endpoint lies in $S$ and the other in $\bar S$,
the coordinate equals $+1$ or $-1$ and survives. Hence the nonzero coordinates
are the edges of $\Gph$ crossing $(S,\bar S)$.
\end{proof}

\begin{intuitionbox}
Stacking the row vectors $x_1^\top,\dots,x_n^\top$ forms an
$n\times\binom{n}{2}$ matrix $\mathbf{B}$ that pads the signed vertex--edge
incidence matrix of Chapter~31 with zero columns on non-edges (so
$\Lap = \mathbf{B}\mathbf{B}^\top$, just as in Chapter~31). Summing $x_v$ over
$v\in S$ cancels every internal edge of $S$ and leaves only the cut boundary
$\partial S$ (the set of edges crossing $(S,\bar S)$). If we could, for any
$S$, pull out one nonzero coordinate of $\sum_{v\in S} x_v$, we would learn an
edge leaving $S$ and could merge components round by round. Because
$\sum_{v\in S} x_v$ has $\binom{n}{2}$ coordinates, we cannot store it directly;
instead we store a compressed linear sketch $\mathsf{Sk}(x_v)$ per vertex and
use linearity: the sum of the sketches equals the sketch of the sum.
\end{intuitionbox}

\subsection{\texorpdfstring{$L_0$}{L0} sampling}

For a vector $x\in\R^N$, write $\norm{x}_0 = \abs{\operatorname{supp}(x)}$ for
its \emph{$L_0$ count} --- the number of nonzero coordinates of $x$ (often
called the ``$\ell_0$ norm,'' though scaling $x$ leaves $\norm{x}_0$ unchanged).
An \emph{$L_0$ sampler} compresses $x$ linearly into far fewer than $N$ bits
and still recovers one uniformly random coordinate from $\operatorname{supp}(x)$.

\begin{definition}[$L_0$ sampler]\label{ch40:def-l0}
Let $N \ge 1$ be the vector dimension and $\delta \in (0,1)$ a failure-probability
bound. An \emph{$L_0$ sampler} is a randomized linear map
$\mathsf{Sk}:\R^N\to\R^k$ together with a recovery procedure $\mathsf{Rec}$
such that, given only $\mathsf{Sk}(x)$ for any nonzero $x\in\R^N$:
\begin{enumerate}
\item $\mathsf{Rec}\bigl(\mathsf{Sk}(x)\bigr)$ succeeds with probability at
least $1-\delta$, outputting an index $i\in\operatorname{supp}(x)$;
\item conditioned on succeeding, every $i\in\operatorname{supp}(x)$ is chosen
with probability $(1\pm\delta)/\norm{x}_0$.
\end{enumerate}
Assuming integer entries bounded by $\poly(N)$, such samplers exist storing
$s = \Oh\bigl(\log^2 N \cdot \log(1/\delta)\bigr)$ bits in total.
\end{definition}

How do we build a linear map that isolates a single nonzero coordinate when we
do not know $\norm{x}_0$ in advance? We \emph{subsample by geometric levels}
(Figure~\ref{ch40:fig-l0-sampler}). Using a random hash function fixed before
the stream starts, assign coordinates to nested subsets
$S_0 \supseteq S_1 \supseteq \cdots \supseteq S_L$ with $L = \ceil{\log_2 N}$ so
that each coordinate $i$ lands in level $S_j$ with probability $2^{-j}$. At the
level $j \approx \log_2 \norm{x}_0$, the expected number of nonzero coordinates
of $x$ surviving in $S_j$ is $\norm{x}_0 \cdot 2^{-j} \approx 1$, giving a
constant probability that $x$ restricted to $S_j$ is \emph{$1$-sparse} (has
only one nonzero entry).

To decode a $1$-sparse level linearly, pick a prime $p > N$ and a random seed
$r \in \set{1,\dots,p-1}$, and maintain three running linear sums over
$i\in S_j$:
\[
  P_j \;=\; \sum_{i\in S_j} x_i,
  \qquad
  Q_j \;=\; \sum_{i\in S_j} i\,x_i,
  \qquad
  F_j \;=\; \sum_{i\in S_j} x_i\, r^i \bmod p.
\]
When $S_j$ contains a single nonzero index $i^\star$ with value $a \neq 0$, we
have $P_j = a$ and $Q_j = a\,i^\star$, so dividing recovers
$i^\star = Q_j / P_j$. The third sum $F_j$ acts as a polynomial
\emph{fingerprint}: when $S_j$ truly has one nonzero entry, $F_j$ matches
$P_j \cdot r^{Q_j/P_j} \bmod p$, whereas if two or more nonzero coordinates
collide in $S_j$, the random base $r$ causes a mismatch with probability at
least $1 - N/p$. Running all $L+1$ levels in parallel (and repeating
$\Oh(\log(1/\delta))$ times so at least one copy hits a $1$-sparse level) gives
Definition~\ref{ch40:def-l0}.

\begin{whybox}
\textbf{Why exact linearity handles deletions.} The level hash functions and
fingerprint seed $r$ are chosen once before the stream begins, and every gadget
slot stores a linear combination $\sum_i c_i x_i$ with fixed coefficients $c_i$.
When token $(\set{u,w},\Delta)$ arrives ($\Delta\in\set{+1,-1}$, $u<w$), we add
$+\Delta$ to coordinate $\set{u,w}$ of $x_u$ and $-\Delta$ to coordinate
$\set{u,w}$ of $x_w$, updating each stored sum by $\pm \Delta\, c_{\set{u,w}}$.
Inserting an edge and later deleting it leaves every sum numerically identical
to its state before the edge ever arrived.
\end{whybox}

\subsection{Connectivity in dynamic streams (AGM sketching)}

Now combine incidence vectors with $L_0$ sampling, following the
Ahn--Guha--McGregor (AGM) algorithm. Recall Bor\r{u}vka's connectivity strategy
from Chapter~6: in each parallel round, every current connected component picks
one outgoing edge and merges with the neighbor on the other end. To run
Bor\r{u}vka after the stream finishes, we maintain for each vertex $v$ a bank of
$R = \ceil{\log_2 n}$ independent $L_0$ sketches of $x_v$ --- one fresh sketch
per Bor\r{u}vka round.

\begin{algorithm}[H]
\caption{\textsc{SketchConnectivity} (Ahn--Guha--McGregor)}
\label{ch40:alg-agm}
\DontPrintSemicolon
\KwIn{turnstile edge stream on $V=\set{1,\dots,n}$; $R=\ceil{\log_2 n}$ rounds}
\KwOut{a spanning forest $F$ of the final graph (with high probability)}
\textbf{During the stream:} for each $v\in V$, maintain $R$ independent $L_0$ sketches
$\mathsf{Sk}_1(x_v),\dots,\mathsf{Sk}_R(x_v)$, updated linearly per token\;
\textbf{Post-processing (Bor\r{u}vka merges):}\;
$\mathcal{C}\gets$ partition of $V$ into $n$ singletons;\quad $F\gets\emptyset$\;
\For{$r=1$ \KwTo $R$}{
  \ForEach{component $S\in\mathcal{C}$}{
    compute the component sketch $\mathsf{Sk}_r\!\bigl(\sum_{v\in S}x_v\bigr) \gets \sum_{v\in S}\mathsf{Sk}_r(x_v)$\;
    run $\mathsf{Rec}$ on it to sample a nonzero coordinate (an edge leaving $S$, if any)\;
  }
  \ForEach{sampled edge $\set{u,v}$}{
    \lIf{$\textsc{Find}(u)\neq\textsc{Find}(v)$}{add $\set{u,v}$ to $F$ and $\textsc{Union}(u,v)$}
  }
  update $\mathcal{C}$ to the merged components\tcp*{skipping repeats keeps $F$ acyclic}
}
\Return $F$\;
\end{algorithm}

\begin{whybox}
\textbf{Why the sum-of-sketches step samples a cut edge.} By linearity of
$\mathsf{Sk}_r$,
\[
  \sum_{v\in S}\mathsf{Sk}_r(x_v) \;=\; \mathsf{Sk}_r\!\Bigl(\sum_{v\in S} x_v\Bigr),
\]
and by Lemma~\ref{ch40:lem-boundary} the vector $\sum_{v\in S} x_v$ is nonzero
on and only on the cut $\partial S$. Running $\mathsf{Rec}$ therefore returns a
uniformly random edge crossing $(S,\bar S)$ whenever $\partial S \neq \emptyset$
(Figure~\ref{ch40:fig-boruvka}).

\textbf{Why $R=\ceil{\log_2 n}$ fresh sketches suffice.} In round $r$, every
component that is not yet a full connected component of $\Gph$ has
$\partial S \neq \emptyset$, samples an outgoing edge, and merges with at least
one other component. That halves the number of active non-maximal components
every round, finishing in at most $\ceil{\log_2 n}$ rounds. Round $r$ must use
a fresh sketch $\mathsf{Sk}_r$ whose random hash bits are independent of rounds
$1,\dots,r-1$: the vertex sets $S\in\mathcal{C}$ queried in round $r$ were
formed from the random edges sampled in earlier rounds, so reusing an old sketch
would let past randomness influence the current query set and invalidate
Definition~\ref{ch40:def-l0}'s success bound.
\end{whybox}

\begin{complexitybox}
Across $R=\ceil{\log_2 n}$ rounds there are at most $n\ceil{\log_2 n}$
component queries. Setting each sampler's failure probability to
$\delta = 1/n^3$ makes all queries succeed simultaneously with probability at
least $1 - \Oh((\log n)/n^2)$ by a union bound. With $N=\binom{n}{2}$ (so
$\log N = \Th(\log n)$), each $L_0$ sketch uses
$\Oh(\log^2 N \cdot \log(1/\delta)) = \Oh(\log^3 n)$ bits
(Definition~\ref{ch40:def-l0}). Storing $R=\Oh(\log n)$ independent sketches per
vertex gives $\Oh(\log^4 n)$ bits per vertex and $\Oh(n\log^4 n)$ bits total in
one pass; refined $L_0$ constructions tighten this to $\Oh(n\log^3 n)$ bits.
Compared with the insertion-only forest's $\Oh(n\log n)$ bits
(Algorithm~\ref{ch40:alg-forest}), the extra logarithmic factors are the price
paid to tolerate arbitrary deletions.
\end{complexitybox}

\begin{connectionbox}
With $\mathbf{B}\in\R^{n\times\binom{n}{2}}$ having row $v$ equal to $x_v^\top$
and $\mathbf{1}_S\in\set{0,1}^n$ denoting the indicator vector of $S$,
Lemma~\ref{ch40:lem-boundary} states that $\sum_{v\in S} x_v = \mathbf{B}^\top\mathbf{1}_S$
has $L_0$ count $\norm{\mathbf{B}^\top\mathbf{1}_S}_0 = \abs{\partial S}$
(matching the squared $L_2$ identity
$\norm{\mathbf{B}^\top\mathbf{1}_S}_2^2 = \mathbf{1}_S^\top\Lap\mathbf{1}_S = \abs{\partial S}$
from Chapter~31). Graph sketching runs Bor\r{u}vka's algorithm (Chapter~6) over
compressed columns of $\mathbf{B}^\top$; Ahn, Guha, and McGregor extended the
same incidence-sketch method to $k$-edge-connectivity, spanners, and cut/spectral
sparsifiers in turnstile streams.
\end{connectionbox}

\section{Approximate triangle counting}
\label{ch40:triangles}

Let $T$ be the number of triangles ($3$-cycles $\set{u,v,w}$) in $\Gph$.
Triangle counts measure local clustering --- how often a two-edge path, called a
\emph{wedge}, is closed by a third edge --- and determine statistics such as the
global clustering coefficient ($3T$ divided by the number of wedges in $\Gph$).
Computing $T$ without error in one pass requires $\Om(n^2)$ bits
(Theorem~\ref{ch40:thm-lb-tri}), so we estimate $T$ randomly instead.

\subsection{One-pass wedge-sampling estimator}

\begin{intuitionbox}
A triangle has three edges, one of which arrives first in the stream. Suppose
we pick one stream edge $e^\star=\set{u,v}$ uniformly at random, pick a third
vertex $w\notin\set{u,v}$ uniformly at random, and watch the rest of the stream
to see whether both remaining edges $\set{u,w}$ and $\set{v,w}$ appear later to
close the wedge at $w$. Every triangle in $\Gph$ has a known probability of
having its earliest edge chosen as $e^\star$ and its opposite vertex chosen as
$w$, so scaling the $0/1$ outcome by the reciprocal of that probability gives an
estimate whose expected value equals $T$.
\end{intuitionbox}

How do we pick a uniformly random edge $e^\star$ from a stream $e_1,\dots,e_m$
when we do not know the stream length $m$ ahead of time? Use \emph{reservoir
sampling}: keep one candidate edge $e^\star$, and when the $t$-th edge $e_t$
arrives ($t=1,2,\dots$), replace $e^\star$ with $e_t$ with probability $1/t$.
Edge $e_i$ is chosen when it arrives with probability $1/i$ and survives every
later step $t = i+1,\dots,m$ with probability
\[
  \frac{1}{i}\cdot\Bigl(1-\frac{1}{i+1}\Bigr)\Bigl(1-\frac{1}{i+2}\Bigr)\cdots\Bigl(1-\frac{1}{m}\Bigr)
  \;=\; \frac{1}{i}\cdot\frac{i}{i+1}\cdot\frac{i+1}{i+2}\cdots\frac{m-1}{m}
  \;=\; \frac{1}{m},
\]
so at stream end $e^\star$ is uniformly distributed over $\set{e_1,\dots,e_m}$.

In the Buriol et al.\ one-pass estimator (Algorithm~\ref{ch40:alg-tri}),
whenever reservoir sampling replaces $e^\star$ with the current edge
$e_t=\set{u,v}$, we also draw a fresh uniformly random vertex
$w\in V\setminus\set{u,v}$ and reset two boolean flags $a,b$ to false; on
subsequent tokens that do not replace $e^\star$, we set $a$ when $\set{u,w}$
appears and $b$ when $\set{v,w}$ appears. At stream end let $X\in\set{0,1}$ be
the \emph{indicator random variable} equal to $1$ if both $a$ and $b$ are true
and $0$ otherwise (so $\mathbb{E}[X]=\Pr[X=1]$). Each triangle $\set{u,v,w}$ is
caught if and only if the final reservoir choice $e^\star$ landed on its
earliest edge in the stream and the random vertex choice picked its third
vertex, an event of probability $\frac{1}{m}\cdot\frac{1}{n-2}$. Hence
\[
  \mathbb{E}[X] \;=\; \frac{T}{m\,(n-2)},
  \qquad\text{so}\qquad
  \widehat T \;=\; m\,(n-2)\,X
\]
is an \emph{unbiased estimator} of $T$, meaning $\mathbb{E}[\widehat T]=T$.
Recall that the \emph{variance} $\operatorname{Var}[Y] =
\mathbb{E}\bigl[(Y-\mathbb{E}[Y])^2\bigr]$ measures squared spread around the
mean: averaging $s$ independent copies $\bar T = \frac{1}{s}\sum_{\ell=1}^s
\widehat T_\ell$ divides the variance by $s$, and \emph{Chebyshev's inequality},
\[
  \Pr\bigl[\abs{\bar T - T} \ge \eps T\bigr] \;\le\; \frac{\operatorname{Var}[\bar T]}{\eps^2 T^2},
\]
bounds the chance that the average strays outside $(1\pm\eps)T$.

\begin{recoverybox}
\textbf{Pause and think}: Why is exact triangle counting impossible in small space during a single pass? If we see edges $\{a,b\}$ and $\{b,c\}$ early on, we cannot predict whether $\{a,c\}$ will appear later. Detecting every triangle without error requires remembering nearly every two-edge path seen so far, which takes $\Om(n^2)$ bits in the worst case.
\end{recoverybox}

\begin{algorithm}[H]
\caption{\textsc{TriangleEstimate} (one independent copy)}
\label{ch40:alg-tri}
\DontPrintSemicolon
\KwIn{insertion stream of simple-graph edges on $V=\set{1,\dots,n}$}
\KwOut{unbiased estimate $\widehat T$ of the triangle count $T$}
$m \gets 0$;\quad $e^\star \gets \text{null}$;\quad $w \gets \text{null}$;\quad $a \gets \text{false}$;\quad $b \gets \text{false}$\;
\ForEach{arriving edge $e$}{
  $m \gets m + 1$\;
  \eIf{a coin of heads probability $1/m$ lands heads}{
    $e^\star \gets e$ \tcp*{reservoir update: $e^\star = \set{u,v}$}
    pick $w \in V\setminus\set{u,v}$ uniformly at random;\quad $a \gets \text{false}$;\quad $b \gets \text{false}$\;
  }{
    let $\set{u,v} = e^\star$\;
    \lIf{$e = \set{u,w}$}{$a \gets \text{true}$}
    \lIf{$e = \set{v,w}$}{$b \gets \text{true}$}
  }
}
\lIf{$a \text{ and } b$}{$X \gets 1$ \textbf{else} $X \gets 0$}
\Return $\widehat T \gets m\,(n-2)\,X$\;
\end{algorithm}

\begin{whybox}
\textbf{Unbiasedness.} Fix a triangle $\tau=\set{u,v,w}$ in $\Gph$, and let
$e_{i_\tau}$ be whichever of its three edges appears earliest in the stream, say
$\set{u,v}$. Because $\Gph$ is simple, the other two edges $\set{u,w}$ and
$\set{v,w}$ both appear at positions strictly greater than $i_\tau$. By the
reservoir telescoping calculation, $e^\star$ ends up at position $i_\tau$ (being
chosen at step $i_\tau$ and never overwritten afterward) with probability
$1/m$; conditioned on this, $w$ is chosen as the third vertex of $\tau$ with
probability $1/(n-2)$, and both flags $a,b$ are then set to true during steps
$j > i_\tau$. A single copy can catch at most one triangle (uniquely determined
by $e^\star$ and $w$), so the catch events $E_\tau$ are disjoint across the $T$
triangles, giving
\begin{align*}
  \mathbb{E}[X]
  &\;=\; \sum_{\tau} \Pr[E_\tau] \;=\; \sum_{\tau} \frac{1}{m\,(n-2)} \;=\; \frac{T}{m\,(n-2)},\\
  \mathbb{E}[\widehat T]
  &\;=\; m\,(n-2)\,\mathbb{E}[X] \;=\; T.
\end{align*}
\end{whybox}

\begin{complexitybox}
One copy stores $\Oh(1)$ words (stream counter $m$, edge $e^\star$, vertex $w$,
and two bits $a,b$). Running
\[
  s \;=\; \Oh\!\Bigl(\frac{1}{\eps^2}\cdot\frac{m\,n}{T}\cdot\log\frac{1}{\delta}\Bigr)
\]
independent copies (partitioned into groups for a median-of-means boost, or
$\Oh\bigl(\frac{m\,\Delta}{\eps^2 T}\log\frac{1}{\delta}\bigr)$ in two-pass and
neighborhood-sampling refinements where $\Delta$ bounds how many triangles share
an edge; see Exercise~\ref{ch40:ex-tri-var}) yields a $(1\pm\eps)$ estimate with probability at
least $1-\delta$. When $T$ is large this space is sublinear in $m$; as $T$
shrinks toward $0$ the sample count blows up, which
Theorem~\ref{ch40:thm-lb-tri} shows is unavoidable.
\end{complexitybox}

\begin{labbox}
The running graph has two triangles, $\set{1,2,4}$ and $\set{6,7,8}$, so $T=2$,
$m=10$, and $n=8$, giving $\widehat T=10\cdot 6\cdot X=60X$ per copy. The
triangle $\set{6,7,8}$ has edges at stream positions $3\,(6,7)$, $9\,(7,8)$, and
$10\,(6,8)$, with earliest edge $(6,7)$ at position $3$. A copy catches
$\set{6,7,8}$ if and only if the final reservoir sample is $i=3$ and the random
vertex is $w=8$: probability $\frac{1}{10}\cdot\frac{1}{6}=\frac{1}{60}$,
contributing $60\cdot\frac{1}{60}=1$ to $\mathbb{E}[\widehat T]$. Triangle
$\set{1,2,4}$ (positions $2,4,6$) contributes another $1$, so
$\mathbb{E}[\widehat T]=2=T$. Each single copy outputs $0$ with probability
$29/30$ and $60$ with probability $1/30$; only the average across many copies
concentrates near $2$.
\end{labbox}

\subsection{Frequency moments and the AMS sketch}
\label{ch40:ams}

Reservoir sampling breaks when edges can be deleted. In turnstile streams, we
track counts of degrees, wedges, and higher-order subgraphs through
\emph{frequency moments}, introduced by Alon, Matias, and Szegedy (AMS) in 1996.
Suppose items $e$ in a universe $U$ accumulate net integer counts $f_e \in \Z$
over the stream (for instance, $f_v = \deg(v)$ when each edge increments its two
endpoints, so $\frac{1}{2}\sum_v f_v^2 - m = \sum_v \binom{\deg(v)}{2}$ counts
all wedges in $\Gph$). For $k \ge 0$, the \emph{$k$-th frequency moment} is
$F_k = \sum_{e\in U} \abs{f_e}^k$: $F_0$ counts distinct active items,
$F_1 = \sum_e \abs{f_e}$ counts total weight, and $F_2 = \sum_e f_e^2 = \norm{f}_2^2$
is the squared Euclidean norm.

\begin{intuitionbox}
How can we estimate $F_2 = \sum_e f_e^2$ in $\Oh(\log\abs{U})$ bits per counter
without storing the individual counts $f_e$? Draw a \emph{$4$-wise independent}
hash function $h: U \to \set{-1,+1}$: a random sign function whose values on any
four distinct items $e_1,e_2,e_3,e_4$ are mutually independent fair coin flips
on $\set{-1,+1}$ (so $\mathbb{E}[h(e)]=0$ and $\mathbb{E}[h(e)^2]=1$), yet $h$
is specified by a degree-$3$ polynomial over a finite field using only four
$\Oh(\log\abs{U})$-bit coefficients rather than a full lookup table.

Keep a single scalar accumulator $Z$, initialized to $0$. On each stream token
$(e,\Delta)$ with $\Delta\in\set{+1,-1}$, update
\[
  Z \;\gets\; Z + \Delta \cdot h(e).
\]
At the end of the stream, $Z = \sum_e f_e\, h(e)$. Its square $Y = Z^2$ is an
unbiased estimator of $F_2$:
\begin{align*}
  \mathbb{E}[Y]
  &\;=\; \mathbb{E}\Bigl[\sum_e f_e^2\, h(e)^2 \;+\; \sum_{e \neq e'} f_e f_{e'}\, h(e)h(e')\Bigr]\\
  &\;=\; \sum_e f_e^2 \cdot \mathbb{E}[h(e)^2] \;+\; \sum_{e \neq e'} f_e f_{e'}\,\mathbb{E}[h(e)]\,\mathbb{E}[h(e')]
  \;=\; F_2,
\end{align*}
where pairwise independence zeroes out every cross-term $e \neq e'$. Why require
$4$-wise rather than $2$-wise independence? Because bounding the variance
$\operatorname{Var}[Y] = \mathbb{E}[Z^4] - F_2^2$ expands $Z^4$ into products of
four signs $h(e_1)h(e_2)h(e_3)h(e_4)$; $4$-wise independence zeroes every term
with an unmatched item and leaves $\operatorname{Var}[Y] \le 2 F_2^2$.

To turn this noisy unbiased estimate into a $(1\pm\eps)$ approximation with
failure probability at most $\delta$, arrange $d \times w$ independent
accumulators $Z_{r,c}$ in $d$ rows of width $w = \ceil{8/\eps^2}$
(Figure~\ref{ch40:fig-ams-sketch}). Averaging each row
$\bar Y_r = \frac{1}{w}\sum_{c=1}^w Z_{r,c}^2$ cuts the variance to at most
$2F_2^2/w \le \frac{1}{4}\eps^2 F_2^2$, so by Chebyshev's inequality each row
falls outside $(1\pm\eps)F_2$ with probability at most $1/4$. Taking the median
across $d = \ceil{16\ln(1/\delta)}$ independent rows fails only if at least half
the rows err simultaneously, driving the failure probability below $\delta$.
\end{intuitionbox}

\section{What small space cannot do}
\label{ch40:lower}

The algorithms above are nearly matched by space lower bounds proved through
\emph{communication complexity}, which measures how many bits two players must
exchange to evaluate a joint function of their private inputs. Split an edge
stream $\sigma$ into a prefix held by Alice and a suffix held by Bob. Any
one-pass streaming algorithm using $s$ bits of memory turns into a
\emph{one-way protocol} (a single message from Alice to Bob, with no reply):
Alice feeds her prefix into the streaming algorithm, sends the resulting $s$-bit
memory state $S$ to Bob, and Bob feeds his suffix starting from $S$ to read off
the answer. Any lower bound on one-way communication therefore lower-bounds $s$.

\begin{theorem}[Connectivity needs $\Om(n)$ space]\label{ch40:thm-lb-conn}
Any one-pass streaming algorithm that decides connectivity --- even a randomized
one succeeding with probability at least $2/3$ on every input --- uses $\Om(n)$
bits of space.
\end{theorem}

\begin{proof}[Proof idea]
Reduce from one-way \textsc{Index}: Alice holds a bitstring $y\in\set{0,1}^N$,
Bob holds an index $k\in\set{1,\dots,N}$, and Bob must output $y_k$ after
receiving a single message from Alice. Because Alice does not know which
coordinate $k$ Bob will inspect, any message of $o(N)$ bits confuses distinct
strings and fails; even with shared randomness and error $\le 1/3$, one-way
\textsc{Index} requires $\Om(N)$ bits.

Build a graph on $n = 2N+1$ vertices consisting of pairs $(u_1,v_1),\dots,(u_N,v_N)$
plus one hub vertex $z$ (so $N=(n-1)/2=\Th(n)$; Figure~\ref{ch40:fig-lb}). Alice
streams edge $\set{u_i,v_i}$ for each $i$ with $y_i=1$ and sends the algorithm's
$s$-bit state $S$ to Bob. Bob then streams $\set{z,u_i}$ for all
$i\in\set{1,\dots,N}$ and $\set{z,v_j}$ for all $j\neq k$. Every vertex except
$v_k$ is now directly linked to $z$, while $v_k$ has only one possible incident
edge in the entire graph, namely $\set{u_k,v_k}$. Thus the final graph is
connected if and only if $y_k=1$, forcing $s = \Om(N) = \Om(n)$.
\end{proof}

Semi-streaming connectivity ($\Oh(n\log n)$ bits) is therefore optimal up to a
logarithmic factor. Exact distances require far more memory:

\begin{theorem}[Exact distances and low stretch require polynomial space]\label{ch40:thm-lb-dist}
Any one-pass algorithm that, for a designated vertex pair $(u,v)$, distinguishes
$\dist(u,v)\le d$ from $\dist(u,v)>d$ without error (or with bounded error
$\le 1/3$) requires $\Om(n^2)$ bits in the worst case --- up to constant
factors, the entire adjacency matrix. More generally, guaranteeing multiplicative
stretch at most $2k-1$ in one pass requires $\Om(n^{1+1/k})$ bits, matching
Algorithm~\ref{ch40:alg-spanner} up to logarithmic factors.
\end{theorem}

\begin{intuitionbox}
The spanner lower bound reads the Moore bound (Lemma~\ref{ch40:lem-moore}) in
reverse. Explicit constructions produce graphs of girth at least $2k+1$ with
$\Th(n^{1+1/k})$ edges (for $k=1,2,3,5$, and $\Omega(n^{1+c/k})$ generally). In
any graph of girth $\ge 2k+1$, deleting even a single edge $\set{u,v}$ removes
the unique short link between $u$ and $v$ and forces the shortest remaining
detour around the cycle to have length at least $2k > 2k-1$. Any state $S$ that
certifies stretch at most $2k-1$ on subsets of such a graph must distinguish all
$2^{\abs{E}}$ subgraphs, forcing $s = \Om(\abs{E})$.
\end{intuitionbox}

\begin{theorem}[Triangle detection needs $\Om(n^2)$ space]\label{ch40:thm-lb-tri}
Distinguishing $T=0$ from $T\ge 1$ in one pass (even with error probability
$\le 1/3$) requires $\Om(n^2)$ bits. Consequently no algorithm using $o(n^2)$
bits (space growing strictly slower than $n^2$, so $s/n^2 \to 0$) can certify
triangle-freeness or deliver a multiplicative $(1\pm\eps)$ estimate of $T$ when
$T$ can be $0$ or $1$.
\end{theorem}

\begin{proof}[Proof idea]
Reduce again from one-way \textsc{Index}, now on an $n\times n$ bit matrix
$Y\in\set{0,1}^{n\times n}$ ($N=n^2$ bits; Figure~\ref{ch40:fig-lb-triangle}).
Form a graph on $2n+1$ vertices: left side $U=\set{u_1,\dots,u_n}$, right side
$V=\set{v_1,\dots,v_n}$, and one query vertex $q$. Alice streams the bipartite
edge $\set{u_i,v_j}$ whenever $Y_{ij}=1$ and passes the $s$-bit state $S$ to
Bob; because Alice's graph is bipartite, it contains zero triangles. Bob holds a
target entry $(i^\star,j^\star)$ and appends just two edges, $\set{q,u_{i^\star}}$
and $\set{q,v_{j^\star}}$. Any triangle in the combined graph must use $q$, and
$q$ touches only $u_{i^\star}$ and $v_{j^\star}$, so the graph contains a
triangle (specifically $\set{q,u_{i^\star},v_{j^\star}}$) if and only if
$Y_{i^\star j^\star}=1$. The $\Om(N)$ one-way \textsc{Index} bound gives
$s=\Om(n^2)$. (For multi-pass streams, reductions from two-party
\textsc{Disjointness} --- where Alice and Bob each hold subsets of $\set{1,\dots,N}$
and require $\Om(N)$ total communication across multiple rounds to test whether
their sets share an element --- prove polynomial space lower bounds per pass.)
\end{proof}

Theorem~\ref{ch40:thm-lb-tri} rules out in $o(n^2)$ space. That is why
Algorithm~\ref{ch40:alg-tri}'s sample count scales inversely with $T$ and grows
beyond $n^2$ as $T\to 0$.
\end{trapbox}

\subsection{Summary of the tradeoffs}

The table below collects the one-pass bounds from this chapter (writing w.h.p.\
for ``with high probability,'' $1 - 1/\poly(n)$, and $\widetilde\Oh(\cdot)$ to
hide $\poly(\log n)$ and $\log(1/\delta)$ factors):

\begin{center}
\begin{tabular}{lllll}
\toprule
problem & model & space (bits) & passes & answer quality \\
\midrule
connectivity & insertion & $\Oh(n\log n)$ & 1 & exact \\
connectivity & turnstile & $\Oh(n\log^3 n)$ & 1 & exact w.h.p. \\
bipartiteness & insertion & $\Oh(n\log n)$ & 1 & exact \\
$(2k{-}1)$-spanner & insertion & $\Oh(n^{1+1/k}\log n)$ & 1 & stretch $2k{-}1$ \\
exact distance & either & $\Om(n^2)$ & 1 & impossible in $o(n^2)$ space \\
\addlinespace[2pt]
triangle count & insertion & $\widetilde\Oh\bigl(mn/(\eps^2 T)\bigr)$ & 1 & $(1{\pm}\eps)$ w.h.p. \\
\addlinespace[2pt]
triangle $T>0$? & either & $\Om(n^2)$ & 1 & impossible in $o(n^2)$ space \\
\bottomrule
\end{tabular}
\end{center}

Three tradeoffs govern algorithm design on streamed graphs:

\begin{itemize}
\item \textbf{Space vs.\ accuracy.} Spanners trade space ($\Oh(n^{1+1/k}\log n)$)
against multiplicative stretch ($2k-1$), and triangle estimators trade sample
count against relative error $\eps$ and density $T$. Communication lower bounds
match both curves up to logarithmic factors.
\item \textbf{Space vs.\ passes.} Allowing multiple passes breaks one-pass
barriers: for example, testing whether $\dist(u,v)\le d$ needs $\Om(n^2)$ bits
in one pass (Theorem~\ref{ch40:thm-lb-dist}) yet drops to $\Oh(n\log n)$ bits in
$d$ passes by advancing one BFS layer per pass (Exercise~\ref{ch40:ex-passes}). Each additional
pass means re-reading a massive dataset from disk or network, trading extra
scans from disk for smaller working memory.
\item \textbf{Insertion-only vs.\ turnstile.} Supporting deletions requires
linear sketches, adding polylogarithmic space and update factors and introducing
a small failure probability. When edges are never deleted, deterministic greedy
structures (Algorithms~\ref{ch40:alg-forest} and~\ref{ch40:alg-spanner}) are
smaller, faster, and error-free.
\end{itemize}

\begin{aestheticbox}
Across this chapter, global cut and connectivity structure compresses to
$\Oh(n\,\poly\log n)$ bits, whereas local exact queries --- whether one specific
pair has distance $\le d$ or one specific triple forms a triangle --- require
$\Om(n^2)$ bits. Semi-streaming algorithms exploit that divide: keep a few words
per vertex, cancel internal edges by boundary algebra, and approximate wherever
communication complexity forbids exactness. Chapter~41 uses the same
compressibility of cuts and quadratic forms to build spectral sparsifiers and
near-linear-time Laplacian solvers.
\end{aestheticbox}

\section{Historical Context and Controversies}

\begin{historybox}
Modern streaming algorithms began in 1996, when Noga Alon, Yossi Matias, and Mario Szegedy showed that frequency moments of numerical streams could be estimated in logarithmic space using randomized linear projections. By the early 2000s, web crawls and router logs outgrew main memory, breaking the random-access assumption of classical graph algorithms. In 2005, Joan Feigenbaum, Sampath Kannan, Andrew McGregor, Siddharth Suri, and Jian Zhang formalized the \emph{semi-streaming model} with its $\Oh(n\,\poly\log n)$-bit budget, proving both positive spanner bounds and the first communication lower bounds showing that exact distances require $\Om(n^2)$ space in one pass, while Ziv Bar-Yossef, T.~S.\ Jayram, Ravi Kumar, and D.~Sivakumar (2002) established the communication lower bounds behind streaming triangle counting.

For dynamic streams with deletions, the turning point came in 2012, when Kook Jin Ahn, Sudipto Guha, and Andrew McGregor introduced \emph{graph sketching}. Representing each vertex by its row of the signed vertex--edge incidence matrix and maintaining $L_0$ sketches across $\Oh(\log n)$ Bor\r{u}vka rounds gave the first single-pass semi-streaming algorithms for connectivity, $k$-edge-connectivity, bipartiteness, and cut sparsification under arbitrary insertions and deletions. Open questions remain active: tightening pass--space tradeoffs for multi-pass shortest paths and matchings, speeding up per-token sketch updates, and determining whether directed $s$--$t$ reachability admits any non-trivial space savings in few passes.
\end{historybox}

\subsection{What We Can Now Do and Its Limitations}
\begin{connectionbox}
\textbf{What we can now do}:
\begin{itemize}
  \item Maintain connected components, bipartiteness, and $k$-edge-connectivity ($k=\poly\log n$) in a single pass using $\Oh(n\,\poly\log n)$ bits, independent of how many billions of edges stream past.
  \item Handle arbitrary edge insertions and deletions in turnstile streams via linear incidence sketches (Algorithm~\ref{ch40:alg-agm}) and AMS frequency-moment sketches.
  \item Approximate all-pairs distances within multiplicative stretch $2k-1$ using $\Oh(n^{1+1/k}\log n)$ bits in an insertion stream (Algorithm~\ref{ch40:alg-spanner}).
\end{itemize}

\textbf{Limitations}:
\begin{itemize}
  \item \emph{Quadratic barrier for exact fine structure}: Exact shortest-path distances, triangle-freeness ($T=0$ vs.\ $T\ge 1$), and exact subgraph detection provably require $\Om(n^2)$ bits in one pass.
  \item \emph{Small failure probability in turnstile sketches}: Linear sketches succeed with high probability ($1 - 1/n^c$); with tiny probability $\le 1/n^c$ over the hash seeds, a failed recovery or fingerprint collision can corrupt the output forest.
  \item \emph{Per-token update cost}: Insertion-only union--find updates take $\Oh(\alpha(n))$ amortized time per edge, whereas turnstile connectivity sketches update $\Oh(\log^3 n)$ to $\Oh(\log^4 n)$ bits of linear combinations per endpoint on every token.
\end{itemize}

\textbf{Where we go next}:
\begin{itemize}
  \item In Chapter~41 (Laplacian Solvers and Electrical Flows), edge-sampling ideas carry over to numerical linear algebra on graphs: sampling edges by effective resistance produces $(1 \pm \eps)$ \emph{spectral sparsifiers} with $\Oh(n \log n / \eps^2)$ weighted edges and drives nearly linear-time Laplacian solvers.
  \item In Chapter~42 (Appendix: Math and Data Structures), we review the supporting data structures (disjoint-set union, segment trees) and linear-algebraic tools (eigenvalue variational bounds and matrix concentration).
\end{itemize}
\end{connectionbox}

\section{Exercises}
\label{ch40:exercises}

\begin{exercise}[Implement: components and a witness]
Implement Algorithm~\ref{ch40:alg-forest} with union by rank and path
compression. Extend it so that, on a disconnected input, it outputs an explicit
vertex pair $(u,v)$ in different components as a certificate of
disconnection. Argue your extension stays within $\Oh(n\log n)$ bits.
\end{exercise}

\begin{exercise}[Prove: bipartiteness parity bits]
Prove that the parity-bit augmentation in
Section~\ref{ch40:connectivity} reports non-bipartiteness if and only if an odd
cycle exists. Show that maintaining $\phi(v)$ under union--find merges
(flipping the smaller tree's parities when roots merge with conflicting
colors) is correct, and bound the total parity-update work across the stream.
\end{exercise}

\begin{exercise}[Break: greedy forest under deletions]
Exhibit a turnstile stream on $4$ vertices on which
Algorithm~\ref{ch40:alg-forest}, naively extended so deletions remove edges
from $F$, reports the wrong number of components. Identify which step
of the correctness proof in Section~\ref{ch40:connectivity} fails, and explain how
linearity in Section~\ref{ch40:sketching} repairs it.
\end{exercise}

\begin{exercise}[Spanner stretch is tight]
For $t=3$ ($k=2$), construct a graph and a stream order on which
Algorithm~\ref{ch40:alg-spanner} produces an $H$ where some original edge
$\set{u,v}$ has $\dist_H(u,v)=3$. Conclude that the stretch bound $2k-1$ can be
attained with equality.
\end{exercise}

\begin{exercise}[Moore bound details]
Write out the degree-cleaning and BFS-ball steps of Lemma~\ref{ch40:lem-moore}
in full: prove carefully that repeatedly deleting vertices of degree $< d/2$
leaves a nonempty subgraph of minimum degree $\ge d/2$, verify that no two tree
paths of length $\le k$ can share an endpoint when girth $\ge 2k+1$, and derive
$\abs{E}\le 2n^{1+1/k}$.
\end{exercise}

\begin{exercise}[$1$-sparse recovery]
A vector $x\in\R^N$ has at most one nonzero coordinate. Given only
$P=\sum_i x_i$ and $Q=\sum_i i\,x_i$, show how to recover the index and value
of the nonzero coordinate, and give an example showing what goes wrong when
$\norm{x}_0 = 2$. Then prove that the polynomial fingerprint
$F = \sum_i x_i\, r^i \bmod p$ (for prime $p>N$ and uniform $r\in\set{1,\dots,p-1}$)
detects $\norm{x}_0 \ge 2$ with probability at least $1 - N/p$.
\end{exercise}

\begin{exercise}[Why fresh sketches per round]
In Algorithm~\ref{ch40:alg-agm}, suppose you reuse a single $L_0$ sketch
across all $R$ Bor\r{u}vka rounds. Construct (or argue) a scenario where reuse
causes a correlated failure because the round-$r$ query sets $S\in\mathcal{C}$
depend on the sketch's random choices from earlier rounds. Why do
$\ceil{\log_2 n}$ independent sketches suffice?
\end{exercise}

\begin{exercise}[Triangle estimator variance]\label{ch40:ex-tri-var}
For Algorithm~\ref{ch40:alg-tri}, compute $\operatorname{Var}[\widehat T]$ for a
single copy in terms of $m$, $n$, and $T$, and deduce the $\widetilde\Oh\bigl(mn/(\eps^2 T)\bigr)$
copy count for a $(1\pm\eps)$ estimate with probability $1-\delta$. Then suppose
a second pass (or neighborhood sketch) checks wedges only among neighbors of
sampled edges, where at most $\Delta$ triangles share any edge, and show how the
bound sharpens when $\Delta \ll n$.
\end{exercise}

\begin{exercise}[Lower bound from \textsc{Index}]
Write out the reduction behind Theorem~\ref{ch40:thm-lb-conn} in full: verify
that the $(2N+1)$-vertex graph in Figure~\ref{ch40:fig-lb} is connected if and
only if $y_k=1$ for every $y\in\set{0,1}^N$ and every $k\in\set{1,\dots,N}$,
and state where the $\Om(N)$ one-way communication lower bound enters.
\end{exercise}

\begin{exercise}[Passes vs.\ space]\label{ch40:ex-passes}
Show that in $d$ passes and $\Oh(n\log n)$ bits of space you can compute exact
single-source BFS distances up to hop depth $d$ in an unweighted streamed graph
(advancing one BFS layer per pass, so a graph of diameter $D$ finishes in $D$
passes). Contrast this with the one-pass $\Om(n^2)$ bound of
Theorem~\ref{ch40:thm-lb-dist} for testing $\dist(u,v)\le d$.
\end{exercise}

\begin{exercise}[Extend: connectivity sketch to MST weight]
Suppose a connected turnstile-streamed graph has integer edge weights in
$\set{1,\dots,W}$, and let $c_i$ be the number of connected components formed
by keeping only edges of weight at most $i$. Prove the telescoping identity
\[
  w(\mathrm{MST}) \;=\; (n - 1) \;+\; \sum_{i=1}^{W-1} (c_i - 1),
\]
and explain how running parallel copies of Algorithm~\ref{ch40:alg-agm} on
weight-thresholded substreams computes $w(\mathrm{MST})$ in one pass when $W$
is small (or approximates it within $1\pm\eps$ by geometric weight thresholds
$(1+\eps)^j$).
\end{exercise}
